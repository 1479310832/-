## 🚀 回家一步克隆指南

```bash
git clone -b jiqimao-mv --single-branch https://github.com/1479310832/-.git jiqimao-mv
```

克隆完成后，直接用 **Antigravity** 打开 `jiqimao-mv` 文件夹，在对话框里说：
* **「我到家啦，我们开始设计二次元 MV 吧！」**
* 或者指定切入点（如：**「先出极其猫的二次元立绘设定和封面曲绘」** / **「按歌词时间轴设计全曲 2D 动画分镜」**）即可直接开整。
