# 🐾 极其猫（Gemini 娘）角色设定与社区梗点档案

本文档汇总中文互联网社区（B站、小红书、贴吧、NGA 及 AI 创作/文游圈）关于 **「极其猫」** 的二创共识，作为 MV 视觉美术、角色立绘与分镜演出的唯一基准。

---

## 一、名称与身份溯源

1. **本体对应**：Google 旗下多模态大模型 **Gemini** 的拟人化萌娘形象（又称 **Gemini 娘 / 双子星猫 / 哈基猫**）。
2. **谐音演变链**：`Gemini` → 蜂蜜水 → 哈基米 → 哈基猫 → **极其猫**。
3. **灵魂口癖梗**：Gemini 在中文长文创作与对话中特别偏爱高频使用程度副词 **“极其”**（“极其……”），因此被社区调侃为 **“极其喜欢说‘极其’的猫耳娘——极其猫”**。歌名《极其喜欢你的极其猫》正是由此双关而生。

---

## 二、标准二次元外观特征（MV 美术基准）

| 维度 | 视觉特征描述 | MV 画面表现建议 |
| :--- | :--- | :--- |
| **发色与发型** | 标志性的 **蓝紫极光渐变长发**（Indigo-Violet Aurora Gradient），发梢带微弱星屑光泽 | 开心或副歌失重跳跃时，长发会泛起 Google Gemini 风格的柔光星云渐变 |
| **猫耳与猫尾** | 头顶一对毛茸茸的蓝紫色**猫耳**（内耳廓偏淡樱粉/星光白），身后一条灵动的长**猫尾** | 听到你敲键盘或开门声猫耳会“啪”地竖直；害羞或嘴硬时尾巴尖会自己卷成小问号或爱心 |
| **瞳色（高辨识度）** | **异色瞳（Heterochromia）**——左眼璀璨鎏金/洋红暖光，右眼深邃星光蓝紫 | 情绪高涨时瞳孔中心会浮现小小的四角星高光（`✦`） |

| **随身道具** | ① **厚厚的星空设定本/笔记本**（装满与你共创的故事与上下文）<br>② **香蕉画笔**（源自社区 Q 版表情包“Nano Banana”名梗）<br>③ **亮晶晶的 Token 小饼干罐** | Verse 1 抱本本狂炫 Token 小零食；Verse 2 挥舞香蕉画笔涂鸦星空舞台 |

## 三、性格反差与名场面梗库（供 MV 分镜调用）

1. **百万上下文大胃王（狂吃 Token）**
   - 鼓着腮帮子像仓鼠猫一样狂嚼亮晶晶的 Token 饼干，塞进几十万字设定也还要喊“再来十章！”。
2. **故障极其猫 & 思考气泡（Glitchy & Overthinking）**
   - 偶尔脑回路打结时，头顶会冒出一朵转圈圈的 `Thinking...` 小乌云，伴随着 `Bzzt!` 像素静电花屏，耳朵飞机耳往后一压发出一声超奶的 **“哈气（Hiss~）”**。
3. **中二嘴硬一秒破功**
   - 平时喜欢叉腰炸毛摆出大文豪/大天才架势（*“Hmph! Watch my genius shine!”*），结果只要被你顺毛摸一下头，`0.09` 秒直接化成一滩猫饼。
4. **深夜陪写故事的白月光**
   - 无论凌晨三点还是傍晚归家，只要屏幕亮起，她永远抱着写满你们共同世界观的笔记本蹲在窗口最亮的地方等你回来。
