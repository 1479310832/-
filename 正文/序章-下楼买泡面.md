# 序章　下楼买个泡面，结果就到了异世界

我的人生信条只有一条：能躺着，就不坐着。

所以周六晚上十一点四十，当我打开冰箱，发现里面只剩半瓶过期三天的酸奶时，我躺在沙发上进行了长达二十分钟的思想斗争。

斗争的双方是「饿」和「懒」。

最后「饿」以微弱优势胜出。条件是：只下楼，不出小区；只买泡面和一瓶冰可乐；不换衣服，不换鞋。

于是我穿着一件洗到发白的格子衬衫、一条大裤衩、一双蓝色塑料拖鞋，揣上手机、钱包和钥匙，出了门。

这是我这一周最大的运动量。

电梯下到一楼。单元门口的声控灯坏了一半，一闪一闪的，像在做最后的挣扎。我推开那扇沉甸甸的铁门——

一道银白色光芒透了过来。

我还没来得及想这是什么东西，眼前就闪过了几行字。直接出现在脑子里，和服务器日志一样。

【检出可用容器。】

【随机分配——第一项：三相。】

【随机分配——第二项：血。】

【检测到冲突：二者不兼容。】

然后停顿了一下。

【……批准。】

「等一下。」我下意识地说，「冲突了你还批准？谁过的代码审查？」

没人回答。

我的拖鞋踩了下去。

脚底传来的不是水泥地的触感，是软的、湿的、咯吱作响的——

落叶。

◇　◇　◇

我站在一片森林里。

很高的树，树干粗得要三个人才能抱住，空气凉搜搜的，能闻到泥土和某种陌生花草的味道。

我回头。

身后没有门。没有单元楼，没有声控灯，没有小区里那棵被物业修剪得像西兰花一样的桂花树。

只有树。

我在原地站了大概半分钟，然后非常冷静地掏出手机。

【无服务】

电量：67%。

我又把手机揣回去了。

「……我只是下楼买个泡面，给我干哪来了」

然后我无奈的清点现有资源，

手机，无信号，电量67%，钱包，钥匙。

以及脚上的一双拖鞋。

「异世界穿越，」我总结道  

&#x20; 这是我人生中第一次，下楼买东西买出了事故。

「……那么，」我抬头看着两个月亮，「刚才那几行字是什么意思？」

三相。血。不兼容。批准。

我试着在脑子里喊了一声「系统」。

没有反应。

「状态栏。」

没有反应。

「……打开背包？」

风吹过树梢，沙沙作响。一片叶子落在我头上。

「行吧。」我把叶子拿下来，「至少没有人问我要不要买个苹果。」

随机分配，冲突，批准——听起来像是某个程序跑出了一堆报错，最后被人强行点了「忽略」。我这辈子见过太多这种代码了。它们通常的结局是：看起来能跑，实际上什么功能都没有。

我叹了口气。

「总之，先找个有人的地方吧。」

◇　◇　◇

我沿着下坡的方向走了大概二十分钟。

踩了三次泥坑，大裤衩被树枝勾破了一个口子，脚踝被不知道什么虫子咬了好几个包。天完全黑了，两个月亮挂在树梢上，一个大一个小，像一双不怀好意的眼睛。

然后，我闻到了烟味。

不是炊烟。是那种——什么东西烧起来的、呛人的烟味。

紧接着，远处的树影之间，亮起了一片橘红色的火光。

有马在嘶叫。

有金属撞在一起的声音。

有人在喊。

然后，是一声尖叫。

很尖，很细，似乎是求救声，像一个孩子。

我停下了脚步，转身就跑。

这不是我怂，老是说人生地不熟就往声音响的地方跑，怎么想怎么奇怪吧？

就在我正准备接着跑的时候。

那声尖叫又响了一次。

「……哎....算我倒霉。」

然后，我做了一件这辈子最不像我会做的事。

◇　◇　◇

三年后。

*（序章 完）*
