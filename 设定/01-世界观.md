# 世界观：艾尔德里亚大陆

> 基调：**标准的剑与魔法异世界**——魔法学院、冒险者公会、教会、魔女、精灵、迷宫、魔兽、等级制度。
> 读者熟悉的东西尽量照常见设定来，只在三个地方动手脚：**咏唱的本质、四元素论的谎言、血祷之罪。**

## 一、魔力与星潮
- 夜空中流动着可见的魔力洋流，称为**「星潮」**，天顶缓慢旋转的银色纹路叫**「星纹」**。
- 人体内有**魔力池**，从星潮中缓慢回复。魔力量天生决定，可通过训练小幅增长。
- **魔力测定**：学院、公会、圣堂都有测定水晶，手按上去会发光，按亮度评级 **F～S**，极少数人是 S＋。
- **元素适性**：测定水晶同时显示属性颜色——火红、水蓝、风绿、土黄。大多数人一种，天才两种。
- 【伏笔】星潮正在**变薄**。近三百年能施展的最高阶法术等级持续下降，圣堂解释为"人心不虔"。

## 二、魔法体系（常见设定）
### 施法三要素
1. **咏唱**：以圣典语逐句念出结构，初级三秒，上级半分钟，超级以上要几分钟甚至多人合唱。
2. **法阵**：手绘、刻印，或以杖尖空画的几何。
3. **触媒**：魔石、粉末、宝石——封装好的魔力，可以代替一部分自身魔力。
   - **违禁触媒·黑晶**：黑色、油光的晶石，能让魔力暴涨，但施术者会失去控制（魔法暴走）。学院与圣堂明令禁止。第07章利奥波德使用；来源未明（伏笔：无名之冠）。

### 咏唱语言：圣典语（词汇与语法取自 Hymmnos／塔语）
所有人的咏唱都用**圣典语**。它的词汇和语法**直接取自游戏《魔塔大陆》（Ar tonelico）的人造语言 Hymmnos**（作者称"塔语"；本作为作者个人创作、不发布，可直接使用原词）。**主角除外**——他不咏唱，只喊技能名或技能别名。

**正文写法（全书统一）**：咏唱用「」括起，**塔语原文在前，中文释义用括号跟在后面**，一句一行；被打断、只念了半句的也要带释义。
> 「Was ki ra, lyuma oz ciel, presia kiafa hynne mea——（星潮啊，倾听我的声音）」
> 「——yehar bale oz fayra！（——火球术！）」

短咏唱可以写在一行里；长咏唱（中级以上）只写开头两三句和最后的发动名，中间用"……"带过，别让咏唱压住节奏。

#### 想音（句首情感词，Hymmnos 原设定）
**每段咏唱的第一句，句首必须带想音**，表示施法者此刻的情绪，由三段组成：

| 段 | 词 | 意思 |
|---|---|---|
| 第一想音（强度） | Rrha | 入迷、极度 |
| | Was | 很、非常 |
| | Wee | 相当 |
| | Fou | 有点 |
| | Ma | 平常状态 |
| | Nn | 没精神 |
| 第二想音（情感） | yea | 高兴 |
| | au | 悲伤 |
| | ki | 认真、专注 |
| | wol | 勇往直前、热血 |
| | guwo | 愤怒 |
| | jyel | 寂寞 |
| | zweie | 真挚、藏着决心 |
| 第三想音（持续） | ga | 希望快点结束 |
| | ra | 希望持续 |
| | erra | 希望永远持续 |
| | wa | 接受现状 |
| | gaya | 不想回到之前的样子 |

> **同一个魔法，谁来念、以什么心情念，想音就不一样。** 想音是写人物的工具——读者一看句首就知道施法者的状态。

**各角色的想音（已在正文使用）**

#### 标准结构（雨泠的理解：**这就是一个函数调用**）
| 段 | 作用 | 程序员视角 | 例 |
|---|---|---|---|
| ① 想音＋呼名 | 表明心情，向星潮借力 | 建立连接 | Was ki ra, lyuma oz ciel（星潮啊） |
| ② 倾听 | 请求开始 | 发起请求 | presia kiafa hynne mea（请倾听我的声音） |
| ③ 元素 | 指定属性 | 类型 | fayra（火） |
| ④ 位置 | 从哪里出现 | 起点坐标 | ween mahin mea（于我掌中） |
| ⑤ 形 | 形状 | 参数：shape | chs bale（化作球） |
| ⑥ 量 | 大小、威力 | 参数：size | wis tyui（其量如粟） |
| ⑦ 径 | 方向、轨迹 | 参数：target | fwal tes yor（其径笔直） |
| ⑧ 限定 | 确认参数不越界 | **参数校验** | Rrha zweie ra, na ruinie yura（不逾分毫，恰如其分） |
| ⑨ 发动 | 执行 | return | ——yehar bale oz fayra！（——火球术！） |

- **发动名固定用 yehar**（释放、解放）＋术式名，术式名用"A oz B"（B 之 A）：yehar viega oz fhyu＝风之刃＝风刃术。
  yehar 在 Hymmnos 词典里的英文释义有一项是 **deallocate（释放内存）**——雨泠听到会吐槽。
- **限定句**字面是"不破坏力量的均衡"（yura＝力量的均衡），本作固定译作"不逾分毫，恰如其分"。

初级魔法完整念完九段，约五到八秒；中级十几段；上级数十段；超级以上要多人合唱。
> **蕾缇希雅的问题就在第⑧段**：她每次都把"不逾分毫，恰如其分"念得最认真，但她的输出端**根本不执行这段校验**。——雨泠："校验写了，但没生效。"

### 魔法位阶
| 位阶 | 例 | 使用者 |
|---|---|---|
| 初级 | 火球术、水弹、照明术 | 学院一年级 |
| 中级 | 炎枪、冰锥、风刃 | 学院毕业水平 |
| 上级 | 爆炎、冰风暴 | 宫廷法师、B级以上冒险者 |
| 超级 | 陨火、大海啸 | 一国屈指可数 |
| 圣级 | 传说 | 史书记载 |
| 神级 | 《晖典》中只出现过一次：**「晖神之日」**——天上落下一束太阳 | —— |

> 用雨泠的话说：**这是一门解释型语言。** 一边读一边跑，读错一个字就报错，而且慢得要命。
> 所以这个世界的法师**慢、贵、脆**——所以**剑活了下来**：骑士把魔力灌进剑身（**灌纹**），近战压制法师是常识。

**「无咏唱瞬发」在艾尔德里亚是理论上不可能的事。** 只有两种解释：神迹，或邪术。

## 三、元素论的谎言
- 世界公认**四大元素：火、水、风、土**。圣堂的《晖典》和学院教材都以此为骨架。
- **冰与雷**在四元素论里不是独立元素，而是水、风的「变式」（上位变化）。市面上有冰魔石、雷魔石，被归类为"水系变异石""风系变异石"，比普通魔石贵。
- 雨泠三年来用魔石施法：**火、冰、雷三种总比别人强一点；纯粹的水、风、土一颗都放不出来。**——他以为是自己手笨，其实是三相亲和。
- 雨泠测出来的却是三种从未见过的颜色：**冰白、雷紫、炎赤**——**三相**。考官当场宣布"水晶坏了"。
- 【主线】三相体系来自**先于四元素论的文明「原初纪」**。四元素论是一次**刻意的历史删除**。

## 四、血祷：大陆第一大罪
用**生命与血液**代替魔力作为法术燃料的技术，称为**「血祷」**。
- 不需要魔力池，不需要触媒，甚至不需要星潮。**它有效。**
- 正因为它有效、且绕开了圣堂对魔法的垄断，圣堂将其列为**不可赦之罪**。
- 魔女的传统魔法正是血祷的一支——这是圣堂猎巫三百年的真正原因。
- **雨泠魔力为零，他的每一个法术都靠哈斯卡的「血魔法」用血施放——按这个世界的定义，他的每一个法术都是血祷。**
- 更糟的是，他不止用自己的血：**他还会抽取尸体流出的血。** 战场上血线从尸体里升起、汇成红色涡流流进他掌心，尸体一具具干瘪——**这个画面和圣堂教科书里描绘的"邪教献祭"一模一样。**

> 他不是因为做了坏事才成为异端的。
> **他只是施法的样子太像邪教了。**（本人："我只是在报销。"）

## 五、五大势力

### ① 学院：阿斯特拉皇立魔导学院（卷一主舞台）
大陆最高魔法学府，建在王都北侧的浮岛群上，钟塔顶端常年亮着观星灯。

**学制（常见设定，照用）**
- **入学考试**：魔力测定＋元素适性鉴定＋实技考试（三十秒内以魔法击中对魔靶）。每年春季一次，秋季有一次**补录**。补录考生需要**担保人的推荐信**（雨泠和维尔的推荐信都是罗森贝格家总长写的）。
- **分班**：按魔力测定分 **S／A／B／C／F** 五个班。S班全是贵族天才，F班是"凑数的"。**魔力量是分班的唯一标准**——所以魔力为零的雨泠，不管实技多离谱，都只能进 F班。
- **学院评分（卷一核心机制之一）**：
  - **个人评分**：在地下迷宫讨伐魔兽，上交**魔石**换分（一层魔兽 1 分，二层 2 分，三层 5 分……），加上实技课成绩。
  - 评分**每周公布排行榜**，贴在主楼大厅。
  - 评分决定一切：**奖学金、宿舍等级、食堂餐券**——评分垫底的只有黑面包，前一百名有肉，前二十名有烤肝。
  - **F班末位淘汰**：学期末评分最低的 F班学生会被劝退。
  - 对雨泠来说：评分＝饭＝血。**失血要靠吃肉补，吃肉要靠评分换。** 这是他一个摸鱼的人拼命刷怪的全部理由。
- **组队制度（卷一核心机制之二）**：
  - 迷宫**一到三层可以单人自由探索**（放学后、周末）；**四层以下、实技课、学院祭对抗赛必须组队**，每队 **3～5 人**。
  - 队伍不成立＝实技学分为零＝留级。
  - 队伍可以跨班组成；**使魔与召唤物在册登记后可计为队员**（这条校规写于两百年前，从没人认真用过）。
  - 队伍评分另算，影响可探索层数与学院祭参赛资格。
- **地下迷宫**：学院的实战场地，一年级最多到第五层。一层洞穴鼠、二层岩蜥、三层甲壳狼……越往下魔兽越强、魔石越值钱，也越接近某个不该存在的东西。
- **护岛大法阵**（第08章引入）：学院四百年前建院时布下、罩着整片浮岛群的结界。形如**十二角星＋中枢**，十二个节点钉在校园各处（已知：第一角主楼、第三角东侧实技场、第六角图书馆塔、第九角西侧温室、第十一角决斗场），中枢在**钟塔**。图书馆一楼地板有它的镶嵌画。"四百年没出过一次错"。【主线】卷一的魔法暴走都发生在节点上；第12章大法阵启动。
- **被抽干的尸体**（第09章）：连别的魔兽和老鼠都不碰，会一直堆着——迷宫三层死胡同攒了一百多具，成了奥托的物证。
- **学院长室**挂着《晖神之日》油画（黑天裂口落下一束金光，下半部跪满了人）。**钟塔顶**的观星灯平台，正好是护岛大法阵的中枢。
- **学院祭**：每年秋末，全学院队伍对抗赛，王族、圣堂、公会都会来观礼——**卷一的高潮舞台**。
- **学院自治权**：学院之内，圣堂无权拘捕、审判。这是四百年前用一场战争换来的，也是雨泠在卷一能活下来的唯一原因。

**人物**
- **学院长 塞勒斯·格兰特**：白胡子老头，好奇心远大于道德感。他护着雨泠，因为"活着的理论革命，比一百本论文值钱"。
- **正统派教授**：咏唱至上，把雨泠视为异端。**革新派教授**：想把他拆开研究。没有一派是真心为他好的。
- **圣堂驻校监察官 奥托**：学院里唯一有权向圣堂打报告的人。鼻子很灵——**他闻得到血。**
- **名誉教授席·艾尔薇拉·夜纹**：精灵符文学者，十年没来过学院，只留下一堆没人看得懂的论文。雨泠在图书馆摸鱼时读到一篇，在页边写了一行批注——**这件事会在卷五找上门来。**

### ② 公会：冒险者公会（卷二主舞台）
冒险者公会与商行的联合体（常见设定，照用）。
- **冒险者等级 F～S**，接委托、赚报酬、升级。登录时需要鉴定魔力与适性（雨泠：零，水晶坏了——又来一次）。
- 签发身份证明与通行证：**流亡者唯一能换到合法身份的地方**，代价是登记在册。
- **垄断全大陆七成的触媒流通。**
- **通讯石**：成对出售的魔石，内封少量魔力，捏住就能和另一块通话（像电话）；用几十次就得拿回商会充能。很贵，罗森贝格商会专营。**卷一末雨泠买了一对，一块给了维尔——卷二开篇它会在牢房里、她的袖子里响起来。**
- 立场：**只认利益。** 不信神，不站队，谁给钱给谁干活。
- **公会总长 格雷戈尔·冯·罗森贝格**：女扮男装的大小姐薇欧拉的父亲。前 S 级冒险者，长得像要吃人，实际是个笨拙的女儿奴。
- **罗森贝格家族长老会**：真正管家族生意与联姻的一群老人。把薇欧拉记作「联姻资产」的是他们。
- 对雨泠的态度**分裂**：
  - 长老会：一个不需要魔力也不需要触媒的法师是整门生意的天敌——**封存他**。
  - 总长：**让他成为家人。**（对外说是商业判断，实际是因为女儿。）卷二开篇起（劫狱、公会登记成婚之后），他当众管雨泠叫「女婿」。

### ③ 教堂：白晖圣堂（卷三主舞台）
信奉晖神，经典《晖典》，垄断"神迹"认定与异端审判。雨泠让它**从内部裂成了两半**：

| | **审判派** | **启示派** |
|---|---|---|
| 核心 | 圣堂骑士团 | 圣女与神殿 |
| 代表 | 骑士团团长 **克蕾雅** | 当代圣女 **伊莉丝** |
| 对雨泠的认定 | 无咏唱＋以血施法＝**血祷异端** | 他降下的太阳正是《晖典》所载「晖神之日」＝**神归来了** |
| 想要什么 | 把他关起来 | 把他供起来 |

> 最讽刺的是：他那一束"神的太阳"，**也是用血换来的。**审判派说"以血唤日，是邪神"；启示派说"神为世人流血"。两边都拿同一场景当证据。
> 克蕾雅与伊莉丝一起长大——克蕾雅是伊莉丝的护卫骑士。圣女为了寻找"神"离开圣堂，团长奉命追回圣女，顺便逮捕异端。**她追的是同一个人。**

### ④ 魔女：黑荆之庭（卷四主舞台）
住在黑荆之森深处的魔女集会。长生、闭锁、以**代价**施法（血、寿命、记忆）。
- 她们是**原初纪燃血一族的后裔**——哈斯卡那一侧的线索都在这里。
- 立场：**灰色。** 不主动害人，但也没有人类的道德观。被圣堂猎杀了三百年。
- **梅露**：集会藏了两百年的"最后的孩子"，从没离开过森林。她走出森林的第一天，就闻到了雨泠身上的血味——"你身上有我们的味道。"

### ⑤ 反派：无名之冠（贯穿全书）
渗透在学院、公会、圣堂内部的秘密结社。成员以"无面的冠"徽记相认。
- 教义：**《晖典》里的神是真实存在的。它没有离开——它被两个凡人封印了。**
- 他们知道雨泠身上的两枚印记就是**那道封印的两半**。
- 目标：让两半在同一个容器里融合，然后**加冕**——神重临，容器的人格被抹除。
- **他们不想杀他。他们想让他成为神。** 这让他们成为圣女伊莉丝最黑暗的镜像。

## 六、原初纪真相（长线骨架）
- 神代末期，星潮本身孕育出一个意志——**星潮之主**，开始吞食地上的生命。
- 两个原本敌对的人联手了：
  - **三相学派最后的大贤者·卡尔**：计算出封印的结构；
  - **燃血一族的圣战士·哈斯卡**：以自己全部的血为封印供能。
- 最后一击是从天而降的一束太阳（阳炎冲击），把星潮之主钉进了星潮深处。两人同死，只留下两枚**残响**——封印的两把锁。
- 幸存者只记得"天上落下了太阳，神救了我们"。三百年后，这件事变成了《晖典》。
  **圣堂的"晖神之日"，其实是一个凡人用血换来的法术。**
- 星潮变薄＝封印在老化，锁需要新的持有者。
  于是那道快撑不住的封印，在世界最薄的一处缝隙边上，**随手抓住了一个正好推开单元门的人**。
  【二者不兼容。……批准。】——那不是系统，是一道**已经没得挑了的封印**。
- 终局命题：加固封印需要一次献祭，最合适的祭品是他。
  **而七个人的答案，是拒绝这个命题本身。** 他自己的答案更简单：「我还没喝上可乐。」
