# 金手指：双响印

推开单元门的那一瞬间，雨泠被"随机抽取"了两个英雄的**技能与先天**，烙在身上显形为两枚印记。
**没有面板、没有提示音、没人解释规则。** 他是用程序员的办法摸清的：
**复现 → 定位 → 记日志 → 写文档。** 他那本笔记是全书最可靠的设定集（也是他上课摸鱼的主要成果）。

| 印记 | 位置 | 来源 | 雨泠的理解 |
|---|---|---|---|
| **三相元素环** | 左手背 | 卡尔 | 代码。一把键盘：Q、W、E，外加一个 R |
| **血纹** | 心口正中 | 哈斯卡 | 电源。**电池是他自己** |

> **核心规则：他没有魔力。** 卡尔给了他元素亲和和十种技能，但他魔力为零。
> 所有技能都通过哈斯卡的先天「血魔法」施放——**不耗魔力，耗血。**
> 雨泠的总结：「代码再好，没电也跑不起来。我这台服务器的电源，是直接接在心脏上的。」
>
> **血有两个来源：他自己的，和尸体的。**
> 他的施法样子——血从伤口和尸体里被抽出来，化成红雾绕着他打旋——**怎么看都是邪教献祭现场**。这就是他成为异端的原因。

### 觉醒与发现（时间线）
| 时期 | 状态 |
|---|---|
| 穿越当晚 | 两枚印记已经烙上，**处于休眠**，肉眼看不见。只闪过一行日志：【三相】【血】【二者不兼容……批准】 |
| 之后三年 | 他以为什么都没抽到。以 Dota 玩家的心态，偷偷喊过无数次"Quas"——**毫无反应**（三相环需要他自己的血第一次唤醒）。只能靠**魔石施法**；冰、雷、火魔石在他手里总是强一点（三相亲和的暗示），风、水、土放不出来 |
| 入学第三天（D3） | 在迷宫里被岩蜥逼到墙角，掌心被石头划破、流着血，走投无路时自嘲地喊了一句"……Quas"——**左手背亮了**。三相环和血纹同时觉醒 |
| 当晚 | 用程序员的办法做实验：唤醒后召球免费；放技能要花血；尸体的血能回收。决定**瞒着所有人，包括维尔**——维尔教过他，血祷是火刑之罪 |

## 壹·卡尔侧：三相元素

### 先天：元素亲和（本作设定）
- 能召出**元素球**，并从元素球获得被动加成。**唤醒之后召球不花血**——亲和是免费的，这是他唯一的"免费午餐"。（**第一次唤醒必须有他自己的血**，所以三年里怎么喊都没用。）
- 测定水晶上显示为三种不存在于四元素论的颜色：冰白、雷紫、炎赤。
- 附带**「万卷之识」**：过目不忘、思维加速。三个小时学会这个世界的文字。
  - 副作用 **残响共感**：偶尔会被卡尔的记忆碎片淹没。雨泠的形容："**像被扔进了一个一百万行、没有注释、作者已经去世的祖传代码库。**"头痛、失眠、做别人的梦。

## 贰·哈斯卡侧：血

### 先天：血魔法（游戏原设定）
**技能消耗生命值，而不是魔力。** 在本作中，它同时适用于卡尔的全部技能——这就是他能施法的唯一原因，也是他被称为异端的唯一原因。
施法时，他心口的血纹发烫，**血从掌心渗出，化作红雾被元素球吸走。看得见。**

### 外部血源：尸血
血魔法不只能烧他自己的血，**也能抽取附近尸体流出的血**。

| 规则 | 内容 |
|---|---|
| 对象 | **只限尸体**（人、魔兽都行）。**活人的血，血纹不认**——包括别人主动献给他的血 |
| 时效 | 必须是**还在流的血**：死后约十分钟内、血未凝固 |
| 范围 | 约十米。越远越慢 |
| 浓度 | 高阶魔兽的血更"浓"：一头龙的 1ml 可能顶人血 10ml。下级魔兽的血稀，要抽很多 |
| 抽取速度 | 不是瞬间的——血丝从伤口里被拉出来，在空中汇成红色的涡流，流进他掌心。**要几秒到十几秒，这段时间他是破绽** |
| 尸体 | 被抽干的尸体迅速干瘪发白 |

**画面（写作必须写出来）**：
战场上一具具尸体的伤口里升起细细的血线，在空中汇成一道缓慢旋转的红色涡流，中心站着一个穿学院制服的男人，掌心悬着一颗元素球，脚下的尸体一具接一具地干瘪下去。
——**不管他本人在想什么（通常是"赚到了"），这个画面都是教科书级别的邪教仪式。**

**这条规则对故事的作用**：
1. **摸鱼的正当出口**：他的名言——「**自己的血是工资，尸体的血是报销。**」能报销的绝不自掏腰包。
2. **以战养战**：先打死小怪，再用小怪的血放大招。迷宫越深、战场越大，他越强。
3. **一对一反而最弱**：决斗、暗杀、没有尸体的场合，他只能烧自己。**敌人一旦发现这一点，就会专门挑他身边没有尸体的时候下手。**
4. **异端的铁证**：圣堂审判派的全部卷宗，都是现场留下的干尸。启示派的解释则是「神在收取祭品」——两派吵的是同一堆干尸。
5. **病娇的一刀**：活人的血不能用，所以当蕾缇希雅第一次发现这条规则时，她很认真地问："……那如果我死了，我的血是不是就能帮上你了？" **他当场吓得把她的法杖都没收了。**

### 技能
| 技能 | 效果 | 血价 |
|---|---|---|
| **心炎** | 以自身为中心爆发火焰，击退周围敌人 | 60ml |
| **沸血之矛** | 以血为矛投出，灼烧可叠加 | 每支 15ml |
| **狂战士之血**（被动·核心） | **失血越多，攻速越快、抗性越高、回复越快** | —— |
| **牺牲** | 跃击。献祭自身大量血液，按目标**最大生命百分比**造成伤害 | 当前血量的约三成 |

### 狂战士之血的副作用：上头
失血越多，他越**热血**——痛觉变钝、胆子变大、嗓门变大、中二台词脱口而出。
**这不是他的性格，是血纹的效果。** 但也不完全不是：它只是把一个普通人心里本来就有的那点热血，调大了音量。
雨泠事后的评价：「那不是我。……好吧，那是喝多了的我。」

## 叁·血量预算（战斗时必须对账）
雨泠 68 公斤，全身血量约 **4.7 升**。（他知道这个，是因为三年前做过一个健康 App 的需求。）

| 失血量 | 状态 | 狂战士之血 |
|---|---|---|
| 0～500ml | 献血水平，没事 | 无 |
| 500～1000ml | 头晕、心跳快、嘴唇发白 | 开始生效 |
| 1000～1400ml | 手脚冰冷、视野发灰、**开始上头** | 明显 |
| **1400ml 以上（约三成）** | **休克线**，瞳孔泛红（赤瞳） | 最大 |
| 2000ml 以上 | 死 | —— |

> 注：这张表只算**他自己的血**。尸血另外计算，不扣他的血量。

**血的来源与回复**：
1. **尸血**——战场上最大的血源，但要有尸体、要时间抽、要在十分钟内；
2. **冰球被动 × 狂战士之血的回复**——两个英雄唯一对得上的接口，乘在一起，把"几周造血"压缩到"几小时"；
3. **电磁脉冲**吃掉别人的魔力，转化成血——**蕾缇希雅超规格的魔法余波，就是他最好的血库**；
4. **吃**。大量地吃。肝、红肉、菠菜。他在学院食堂的饭量是一个传说。

### 为什么他是全世界最抠门的法师
- 平时：**能不放就不放。** 一个急速冷却解决的战斗，绝不放第二个技能。能让小炭干的活，绝不自己干。能让队友打的怪，给队友上个灵动迅捷然后站后面。
  旁人以为他"深藏不露""从不出全力"，其实他只是在省血——以及摸鱼。
- 关键时刻：**热血上头，不算账。** 平时抠了一个月的血，一场战斗全泼出去。
  **这就是七个女角色最怕的事。**

### 战斗节奏（每场大战按这个写）
```
① 摸鱼期：最低血耗，能躲就躲，能让队友打就让队友打（吐槽密度最高）
   ↳ 有尸体了：抽尸血"报销"，红色涡流升起，旁观者开始脸色发白
② 算账期：尸血不够或抽不及，开始花自己的血，他在心里对账（"还剩八百，够两个陨石"）
③ 上头期：有人出事，热血接管，不再算账，别名台词脱口而出
④ 爆发：阳炎冲击／混沌陨石／牺牲收场
⑤ 贫血：站不起来、脸白得像纸——必须有人接手（→ 病娇们的主场）
```

**第⑤步是后宫的舞台：**
| 谁 | 在他倒下之后接住什么 |
|---|---|
| 蕾缇希雅 | **战场**——剩下的敌人，由她用超规格魔法清掉 |
| 薇欧拉 | **代价**——赔款、封口费、伪造报告（全部记账） |
| 奥菲莉娅 | **他的身体**——止血、扛回去、炖猪肝 |
| 伊莉丝 | **名义**——对外宣布"神在休憩"，谁靠近谁就是亵渎 |
| 克蕾雅 | **责任**——善后、上报、把黑锅背走，然后骂他 |
| 梅露 | **敌人**——把剩下的人变成蘑菇（然后问"这样不对吗？"） |
| 艾尔薇拉 | **后果**——算出他这次失了多少血、折了多少元气，然后不告诉他 |

## 伍·连携技（后宫不水的保证）
| 名 | 组合 | 内容 |
|---|---|---|
| **聚怪**（屯野） | ＋蕾缇希雅 | ★ 卷一核心。他满层跑，把魔兽全部拉到身后（拉火车），带回她面前，站在怪堆正中间喊"**朝我打！**"——她全功率轰下来，他用电磁脉冲撑开贴身的"伞"。伞里的魔法被他吃掉转成血，伞外的怪全灭，尸体再抽一轮血，魔石捡一地。**评分、经验、血，一波全有** |
| **输血** | ＋蕾缇希雅 | 大战版的聚怪：她不留任何余地全力释放，他全部吃掉——一口气回满血，接阳炎冲击／混沌陨石 |
| **赤字支付** | ＋薇欧拉 | 整箱触媒砸给他，电磁脉冲吃掉转成血。当场报价记账 |
| **影与幽行** | ＋奥菲莉娅 | 影武者匿踪配合幽灵漫步，暗杀式突入 |
| **圣晖加护** | ＋伊莉丝 | 她的圣术为他承接伤害——**她替"神"流血**，他比自己流血还难受 |
| **苍环之矛** | ＋克蕾雅 | 她冲阵，他超震声波缴械开路，灵动迅捷挂在她身上 |
| **等价交换** | ＋梅露 | 魔女之术替他支付血价——用她的寿命。**她完全不觉得这有什么问题** |
| **刻式** | ＋艾尔薇拉 | 技能预先刻成符文阵地，战时不再现场付血 |

> **关于"聚怪"的细节**：
> - 火系魔法会把尸体烤干，抽不出血；风系把怪切碎，血最多。所以他会点菜："这次用风！火的血都烤没了！"
> - 魔石很硬，炸不坏。
> - **他从来没想过要"治好"她。** 他只是需要她全功率输出。结果她一次次毫无顾虑地放满，反而自己摸到了控制魔力的手感——**误打误撞。**
> - 她学会控制以后，魔法会精确地**绕开他**（不是她本人躲他），伞都不用撑了——但她一直瞒着他。

> **伊莉丝**和**梅露**的连携都是"替他付代价"——一个出于信仰，一个出于无知。
> 他抠门抠了一辈子，唯独受不了**别人替他花钱**——何况花的是命。这是他在卷三、卷四最大的情绪线。
