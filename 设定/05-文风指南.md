# 文风指南

> 目标：**日式轻小说的异世界魔法题材**，西幻中世纪背景。读起来像一本翻译过来的日轻——轻快、吐槽多、对话多、角色萌点鲜明、战斗有"技能名喊出来"的爽感。

## 一、格式（全书统一）

| 项目 | 写法 | 例 |
|---|---|---|
| 对话 | 「」 | 「你只能跟我一组哦。」 |
| 引用中的引用、特殊称呼 | 『』 | 她们叫她『友军杀手』。 |
| 主角的技能名 | 【】，喊出来时放进对话 | 「【急速冷却】！」 |
| 技能别名（台词） | 【】＋破折号 | 「——【卡尔维因的至邪造物】！」 |
| 他人的咏唱 | 「圣典语——（中文释义）」，一句一行 | 「Ventara, lamina tenuis——（风啊，化作薄刃）」 |
| 内心吐槽 | 直接写在叙述里，或用（） | （不，等等，这不对吧。） |
| 场景切换 | 单独一行 `◇　◇　◇` | —— |
| 视角切换（他人视角） | 单独一行 `◆　◆　◆`，下接一句点明是谁 | ◆　◆　◆　——维尔的房间。 |
| 强调 | 少用。必要时用「」框起，不用加粗 | —— |

## 二、结构
- 每卷十二章左右，可在前后加**序章／终章**，中间穿插**间章**（他人视角的短篇）。
- 每章 6000～9000 字，内部用 ◇ 分成 3～6 个场景。
- **章标题**用日轻风格：一句完整的话，带一点吐槽或反差。
  - 例：「下楼买个泡面，结果就到了异世界」「魔力测定为零，但是包食宿」「一个人刷怪的效率实在太低了」「我说了朝我打，没说要这么大」
- **章末**要留钩子：一句台词、一个反转、或者一个他人视角的小片段。
- 卷末可加**后记**（作者吐槽风，可选）。

## 三、叙述

### 主角视角（第一人称"我"）
- **短段落。** 一两句话一段是常态，关键句单独成段。
- **吐槽密度高。** 每个场景至少一处。吐槽方向：
  - 对异世界常识：「咏唱要念八秒？这效率也太低了吧。」
  - 对自己的处境：「穿越第一天就露宿街头，这是什么地狱开局啊。」
  - 对女角色的言行（他常常误读）：「……她刚才是不是说了什么很可怕的话？算了，应该是我听错了。」
- **例外**：主角极度震惊时的内心吐槽，允许用「卧槽」（作者指定，见岳父登场一场）。全卷限用两三次，别变成口头禅。
- **作者的口吻（以作者亲手修订的句子为准）**：主角说话和内心吐槽可以很口语、带方言和口头禅——「给我干哪来了」「你能走个锤子」「恶个der」「搞快点」「哇丢」「亿万负翁」「架构大佬」「氪金法师」「try-catch」。**别写得太端着。**
- **现代梗有，但别刷屏。** 程序员、老玩家的词随便用；过于泛滥的流行语（"绝绝子""yyds"之类）还是不用。
- **不重复解释。** 前文讲过的设定（一千局卡尔、血价、尸血规则）不要每章再讲一遍，一句带过或干脆不提。
- **施法不写键位动作。** 不写「按下R」「R。」「按了一下那个键」之类——召球（心口一烫）→ 喊技能名，就够了。唯一例外是第03章觉醒那一次（作者保留）。电磁脉冲撑的伞，主角口语里可以叫「磁暴」。
- **名台词别刷屏。**「朝我打」「尽管放」这类口号，一个场景喊一次就够，不要在对白、内心、他人视角里反复堆（作者修订第05章时删掉了好几处）。
- **误读是核心笑点。** 女角色的病娇言行，主角经常用一个"合理的"解释糊弄过去；读者看得懂，他看不懂。
  - 「你只能跟我一组哦。」→（大概是太久没人组队，有点怕生吧。）
- **热血的时候，句子变短，吐槽消失。** 反差本身就是爽点。

### 他人视角（间章、章末片段）
- 第三人称，短，一两千字以内。
- 用来：①向读者确认主角没看出来的事（维尔的身份、蕾缇希雅的秘密）；②展示外界对主角的误解（圣堂、贵族、学生们的传言）。
- 误解要夸张：主角在摸鱼 → 别人以为他"深藏不露""从不出全力""在酝酿更可怕的术式"。

## 四、角色说话方式（口吻表）

| 角色 | 口吻 | 例 |
|---|---|---|
| 雨泠 | 随意、有点丧、吐槽多，热血时变短 | 「……行吧。」「赚到了。」「朝我打！全力！」 |
| 蕾缇希雅 | 轻声、礼貌、常道歉，句尾带"哦""呢"；病娇台词也用同样温柔的语气说 | 「对不起……可是，这是我决定好的事哦。」 |
| 维尔（薇欧拉） | 少年腔、轻佻、话多、爱报价；被戳中时声音会突然高半度 | 「兄弟，这顿记你账上。」「我、我有皮肤病！」 |
| 奥菲莉娅 | 敬语、极短、没有情绪起伏 | 「少爷，家族来信了。」 |
| 伊莉丝 | 庄重的敬语，称他「我主」 | 「我主，这是您今日的第三句圣言，我已记录。」 |
| 克蕾雅 | 骑士腔，粗声粗气，被说中时结巴 | 「少、少废话！我只是来确认异端有没有逃跑！」 |
| 梅露 | 天真、句子短、爱问"为什么" | 「为什么不能把他变成蘑菇？」 |
| 艾尔薇拉 | 平静、精确、像在念论文 | 「根据我的推算，你有百分之九十四的概率会选择我。」 |
| 学院长 | 慢悠悠、爱笑、话里有话 | 「嗯……有意思，太有意思了。」 |
| 格雷戈尔（维尔之父） | 粗、短、结巴、音量失控；越紧张脸越凶 | 「你、你你你……」「……你好！！」 |

## 五、世界观质感（中世纪西幻）
- **货币**：铜币／银币／金币（1银＝100铜，1金＝100银）。一顿便饭几枚铜币。
- **照明**：蜡烛、油灯、魔导灯（贵族和学院用）。
- **书写**：羊皮纸、羽毛笔、火漆封印、信鸽。
- **建筑**：石墙、木梁、尖顶、城堡、钟塔、石板路。
- **社会**：国王、贵族（公爵／侯爵／伯爵／子爵／男爵）、骑士、平民；教会权力很大；冒险者公会遍布各城。
- **称呼**：「阁下」「大人」「少爷」「小姐」「团长」「圣女大人」「学院长」。
- **食物**：黑面包、炖菜、烤肉、麦酒、奶酪、腊肠。**没有碳酸饮料，没有泡面**（主角的个人主线）。
- **禁忌**：异世界的人不会说出现代词汇（塑料、手机、电……）。主角带来的现代物品，他们会用自己的理解去描述：「版画」「会发光的小镜子」「奇怪的软木鞋」。

## 六、常见套路清单（可以放心用）
- 魔力测定水晶显示异常 → 全场嘲笑 → 实技震撼全场
- 贵族少爷找茬 → 决斗 → 打脸
- 学院排行榜、学院祭对抗赛、迷宫实习
- 女扮男装的室友（澡堂、厕所、同床、换衣服）
- 被误解为"深藏不露的强者"
- 教会把主角认定为神／异端
- 章末他人视角：「那个男人……到底是什么人？」
