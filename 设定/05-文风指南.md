# 文风指南

> 目标：**日式轻小说的异世界魔法题材**，西幻中世纪背景。读起来像一本翻译过来的日轻——轻快、吐槽多、对话多、角色萌点鲜明、战斗有"技能名喊出来"的爽感。

## 一、格式（全书统一）

| 项目 | 写法 | 例 |
|---|---|---|
| 对话 | 「」 | 「你只能跟我一组哦。」 |
| 引用中的引用、特殊称呼 | 『』 | 她们叫她『友军杀手』。 |
| 主角的技能名 | 【】，喊出来时放进对话 | 「【急速冷却】！」 |
| 技能别名（台词） | 【】＋破折号 | 「——【卡尔维因的至邪造物】！」 |
| 他人的咏唱 | 「塔语原文——（中文释义）」，一句一行。**第一句句首必须带想音**；发动名一律「——yehar ……！」；**被打断、只念了半句的也要带释义** | 「Was ki ra, fhyu, presia kiafa hynne mea——（风啊，倾听我的声音）」「——yehar viega oz fhyu！（——风刃术！）」「Was wol ga, fayra, presia kiafa——（火啊，倾听——）」 |
| 内心吐槽 | 直接写在叙述里，或用（） | （不，等等，这不对吧。） |
| 场景切换 | 单独一行 `◇　◇　◇` | —— |
| 视角切换（他人视角） | 单独一行 `◆　◆　◆`，下接一句点明是谁 | ◆　◆　◆　——维尔的房间。 |
| 强调 | 少用。必要时用「」框起，不用加粗 | —— |

## 二、结构
- 每卷十二章左右，可在前后加**序章／终章**，中间穿插**间章**（他人视角的短篇）。
- **每章 5000～7000 字，内部用 ◇／◆ 分成 6～9 个场景**（作者定；以卷一平均约6300字、8～9个场景为准）。
- **重要的戏一拍一拍演出来，不要用概括带过。**「那天下午，我们在排水渠里干了三个时辰」「后来的事，我记得有点乱」这种一句话跳过一场戏的写法，只能用在真正不重要的过渡上。战斗按血价一步一步写（放了什么、花多少、抽回多少）。
- **每章都要有喘气的戏**：日常、配角、吐槽、闲聊。不要只排"一个核心事件＋一个钩子"（第17～21章字数掉到三千多，就是因为场景砍到了三到五个）。
- 写完用字数自检：少于5000字，先看是不是把该演的戏概括掉了、是不是缺了日常场景。
- **章标题**用日轻风格：一句完整的话，带一点吐槽或反差。
  - 例：「下楼买个泡面，结果就到了异世界」「魔力测定为零，但是包食宿」「一个人刷怪的效率实在太低了」「我说了朝我打，没说要这么大」
- **章末**要留钩子：一句台词、一个反转、或者一个他人视角的小片段。
- 卷末可加**后记**（作者吐槽风，可选）。

## 三、叙述

### 主角视角（第一人称"我"）
- **短段落。** 一两句话一段是常态，关键句单独成段。
- **吐槽密度高。** 每个场景至少一处。吐槽方向：
  - 对异世界常识：「咏唱要念八秒？这效率也太低了吧。」
  - 对自己的处境：「穿越第一天就露宿街头，这是什么地狱开局啊。」
  - 对女角色吓人的言行：「……这话有点吓人啊。」——**吐槽可以；装没听见偶尔一次可以，别成习惯。**
- **例外**：主角极度震惊、或者疼得叫出来的时候，允许用「卧槽」（作者指定；第08章作者自己加了一次）。别变成口头禅。
- **作者的口吻（以作者亲手修订的句子为准）**：主角说话和内心吐槽可以很口语、带方言和口头禅——「给我干哪来了」「你能走个锤子」「恶个der」「又咋咧？」「罪多不压身」「姐姐，审判派的人正满世界找我呢」「肯定啊，哥们直接失联了啊」「搞快点」「哇丢」「亿万负翁」「架构大佬」「氪金法师」「try-catch」。**别写得太端着。**
- **现代梗有，但别刷屏。** 程序员、老玩家的词随便用；过于泛滥的流行语（"绝绝子""yyds"之类）还是不用。
- **不重复解释。** 前文讲过的设定（一千局卡尔、血价、尸血规则）不要每章再讲一遍，一句带过或干脆不提。
- **施法不写键位动作。** 不写「按下R」「R。」「按了一下那个键」之类——召球（心口一烫）→ 喊技能名，就够了。唯一例外是第03章觉醒那一次（作者保留）。电磁脉冲撑的伞，主角口语里可以叫「磁暴」。
- **名台词别刷屏。**「朝我打」「尽管放」这类口号，一个场景喊一次就够，不要在对白、内心、他人视角里反复堆（作者修订第05章时删掉了好几处）。
- **少用「攥紧」这类套路动作。**「攥紧」「攥得指节发白」「手指收紧」之类别当万能情绪表达，一章最多一两次；能用「抓」「藏」「握」的就换掉，更好的是直接写她做了什么、说了什么（作者修订第07章时把「攥」改成了「藏」「抓」）。
- **上头时可以说粗话。** 主角被惹毛、要替人出头时，可以用「老子」「他妈」这种口气（作者修订第06章：「老子替他。」）。平时不用，留给热血的时候。
- **少用「不是……而是……」「不是……是……」句式。** 这种反转句一章最多一两处，能直接说正面的就直接说（「他没想杀我，他要我认输」，别写「他要的不是杀我，是让我认输」）。
- **别写工整的抒情总结句。** 像「一个要我站在后面，冷静地算。／一个要我冲到前面，把血烧光。」这种对仗收尾，作者删掉了。章末、段末不要替读者总结情绪。
- **少替读者解释。** 读者看得懂的就不要让角色再问一遍、说一遍（作者删掉了「你的技能，要用血？」）；分量重的话往轻里说（「他要把那阵风砸到你身上」→「那阵风离你很近」）。
- **煽情的时候，先接住，再用玩笑岔开。** 女主打直球，他先直球回过去（作者指定：主角感情上不迟钝），然后才轮到嘴欠。 他扛不住正经的气氛，会嘴欠、会开荤玩笑、会误读得更离谱（「你一个大男人别总是哭哭啼啼的」「还以为后庭不保呢」「气氛怎么有点蕉灼」）。嘲讽对手可以很损（「你是不是跟你妈一样只会叫床啊？」）。
- **旧梗不要反复用。** 用过的笑点（「搬个箱子都喊腰疼」「摩西分海」这类）别在后面章节再拿出来。荤段子要有分寸：「带薪拉屎」被作者改成了「带薪摸鱼」。
- **动作别刻意重复。**「捋了一下胡子。又捋了一下。又捋了一下。」「清了一下嗓子。又清了一下。」作者都删成了一次（作者修订第17章）。
- **别逐项罗列，一句概括。**「手不见了。袖子不见了，腿也不见了」→「我低头看了看自己，整个人变成了透明」（作者修订第15章）；「家族来信、药到时间了、剑要保养了」→「都是为了罗森贝格家的事」。同理：「X的声音。Y的声音。Z的声音」「第一盏灭了，第二盏，第三盏」这种一样一样数过去的写法少用。回忆蒙太奇这类有意为之的除外。
- **少用「像是……（的）」。**「像是有人把脸埋进了枕头里」「像是走了很远的路」「像是用尺子量过」「像是自己拿剪刀剪的」这类猜测式比喻作者嫌太频繁：能直接写发生了什么就直接写（「接着是一声闷在枕头里的呜」「发尾参差不齐」），可有可无的就删。**比喻整体都要少**：作者修订第16章时，连「像是一直在等一记耳光，等来的是一碗热汤」也删了，「只要按下去，我就是一件填了一半的货」改成了「只要按下去，就被定死了」。宁可直说。
- **别替读者复述、补解释。** 刚写过的事不要再用一两句总结一遍（作者删掉了「短头发的大小姐……她哥哥……」的复述）；读者看得懂的不补刀（「她家就这么做生意」被删）。
- **小事别拆成好几段。**「风很大。／腊肠很香。」这种为了节奏硬拆的单行段，作者合成了一句。单独成段只留给真正的重拍。
- **婚后要有亲密描写（作者指定）**：已成婚的女主，牵手、拥抱、亲吻、同床共枕、早上醒来、撒娇都要写，按日轻尺度——**熄灯即淡出，不写露骨的性描写**。**未满十七岁、尚未成婚的女主（蕾缇希雅）只写纯情**（牵手、靠肩、隔墙道晚安）。
- **婚房初夜（作者指定）**：成婚后要有初夜，**用落红暗写**——熄灯淡出，第二天清晨写床单上一小片已经干了的红、她的反应（害羞＋病娇动作），不正面描写过程。**只写年满十八岁的女主**：维尔（18）、奥菲莉娅（19）可以；**蕾缇希雅、伊莉丝（17）成婚照常，初夜不写，等十八岁以后**。其余女主（克蕾雅21、梅露、艾尔薇拉）按各自成婚节点。
- **病娇要凸显，婚后加码**：每章每个病娇至少一个具体动作；已婚的更要写出"所有／照护／绑定"的那一面（维尔：账本、拽袖子、顺序很重要；奥菲莉娅：记每一次、"伤好得慢一点您就哪儿也去不了"；蕾缇希雅：名单、倒数、隔墙知道谁在哪）。
- **台词已经说明白了，后面不补解释性吐槽。** 作者删掉了第17章蕾缇希雅"锁早了呢"后面三行吐槽（"懂了……正房……石头"）和"跳窗得先申请额度"。
- **病娇要落到动作上。** 每章每个病娇角色至少有一个**具体的行为**（做了什么、改了什么、藏了什么、弄坏了什么），不能只靠一句温柔的狠话（作者指示）。
- **用词：蕾缇希雅在队里是「主力」，不叫「主炮」**（作者指定）。
- **别写「对面全是活人」。** 对手本来就是活的，这话逻辑不通。真正的限制是「场上没有尸体」「只能烧自己的血」，就这么写（作者指定）。
- **套话别反复用。**「我竟然无法反驳」「这个逻辑我竟然挑不出毛病」这类句子用过就别再用，作者改成了「合情合理说是」这种更随口的说法。
- **不写叙述者预告。**「那时候我还不知道，那块石头不到一个月就会响起来」这类站在未来剧透的句子，作者删掉了（作者修订第13章）。
- **收尾别抖机灵。**「是有人在调用接口」被作者改成了「答案很明显了」；「红的。红的。红的。」这种刻意重复也删了。朴素一点。
- **游戏黑话可以直接用**：「主C」（作者把「范围伤害」改成了「主C」）、「天火」（阳炎冲击的俗称）、「良性BUG被修复了」。
- **章末可以正常收尾、写总结句。** 作者偶尔会自己删改（比如第11章删掉了「今天的血，我不省了」），那是作者对那一处的判断，**不要因此把所有收尾句都砍掉**。
- **主角感情上不迟钝。**（作者指定）他感觉得到好感；女主表达好意、打直球时，他直接回应——说出口，不靠内心独白绕开。「应该是我听错了」「大概是问价钱吧」「大概是怕生吧」这类装傻独白**偶尔可以**（一卷几次，当笑点），**不许变成常态**——别把他写成木头。
  - 「你去哪里，我就去哪里哦。」→「行。那就一起。」（作者修订第13章：把原来两句"大概是怕我效率太低吧"的装傻独白删成了一句轻轻的「还好主C还在」——**一句带过的玩笑可以，长篇替她找理由不行**）
- **误读只留给信息差。** 卷一看不出维尔是女孩（他不知道），岳父的紧张被当成暴怒（他没见过这个人）——这些是笑点。**病娇言行他看得出来有点吓人**，可以吐槽「这话有点可怕」，但不把好感曲解成别的。
- **热血的时候，句子变短，吐槽消失。** 反差本身就是爽点。

### 他人视角（间章、章末片段）
- 第三人称，短，一两千字以内。
- 用来：①向读者确认主角没看出来的事（维尔的身份、蕾缇希雅的秘密）；②展示外界对主角的误解（圣堂、贵族、学生们的传言）。
- 误解要夸张：主角在摸鱼 → 别人以为他"深藏不露""从不出全力""在酝酿更可怕的术式"。

## 五、世界观质感（中世纪西幻）
- **货币**：铜币／银币／金币（1银＝100铜，1金＝100银）。一顿便饭几枚铜币。
- **照明**：蜡烛、油灯、魔导灯（贵族和学院用）。
- **书写**：羊皮纸、羽毛笔、火漆封印、信鸽。
- **建筑**：石墙、木梁、尖顶、城堡、钟塔、石板路。
- **社会**：国王、贵族（公爵／侯爵／伯爵／子爵／男爵）、骑士、平民；教会权力很大；冒险者公会遍布各城。
- **称呼**：「阁下」「大人」「少爷」「小姐」「团长」「圣女大人」「学院长」。
- **食物**：黑面包、炖菜、烤肉、麦酒、奶酪、腊肠。**没有碳酸饮料，没有泡面**（主角的个人主线）。
- **禁忌**：异世界的人不会说出现代词汇（塑料、手机、电……）。主角带来的现代物品，他们会用自己的理解去描述：「版画」「会发光的小镜子」「奇怪的软木鞋」。

## 六、常见套路清单（可以放心用）
- 魔力测定水晶显示异常 → 全场嘲笑 → 实技震撼全场
- 贵族少爷找茬 → 决斗 → 打脸
- 学院排行榜、学院祭对抗赛、迷宫实习
- 女扮男装的室友（澡堂、厕所、同床、换衣服）
- 被误解为"深藏不露的强者"
- 教会把主角认定为神／异端
- 章末他人视角：「那个男人……到底是什么人？」
