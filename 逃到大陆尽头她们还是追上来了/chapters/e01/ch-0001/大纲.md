# 第 01 章：泥水、剑阵与无名客

- **所属事件**：E01（E01-01）
- **POV**：雨泠（第一人称「我」）
- **时间与地点**：身穿降临当夜；奥尔兰大陆东北边陲·罗斯韦尔领外围雨夜古道 → 林深废弃猎屋
- **出场角色**：雨泠、伊薇特·冯·罗斯韦尔、叛徒副官加雷斯、四名黑甲死士
- **核心推进**：身穿落地摸清危机 → 撞破白蔷薇马车遭倒戈死士以四方缚魔银桩围杀 → 别扭心软介入、首次触发异常洞察（正文不命名）拆毁阵眼破阵救下伊薇特 → 承担头痛与擦伤代价将其拖入废弃猎屋 → 林外猎犬逼近，伊薇特攥袖质问身份与价码。
- **章末钩子**：伊薇特攥住雨泠湿透的卫衣袖口，以冷冽优雅的口吻质问这个无魔力破阵的无名异乡人究竟是谁、又想要什么价码。
