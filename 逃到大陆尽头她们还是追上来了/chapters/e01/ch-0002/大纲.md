# 第 02 章：披衣、拂晓与第一笔旧账

- **所属事件**：E01（E01-02）
- **POV**：雨泠（第一人称「我」）→ 尾段 `◆　◆　◆` 切入伊薇特第三人称有限视角
- **时间与地点**：雨夜废弃猎屋 → 拂晓林道
- **出场角色**：雨泠、伊薇特·冯·罗斯韦尔、罗斯韦尔家忠心近卫老队长（布兰德）
- **核心推进**：雨泠压下头痛用疑兵假痕引开林外猎犬搜捕队 → 猎屋暗炭前拒绝伊薇特开出的贵族报酬与爵位，随口只留单字「雨」，嫌她发抖随手丢下深灰连帽卫衣后拂晓不告而别 → 首次切入伊薇特第三人称视角，援军赶到，她叠好现代卫衣下令先血洗叛党、再请全领画师画肖像。
- **章末钩子**：伊薇特臂弯抱着那件格格不入的深灰连帽卫衣，平静下令召集全领画师，「那位自称『雨』的阁下，逃不掉的。」
