# 第 03 章：石板街、西行路与白蔷薇封城令

- **所属事件**：E02（E02-01）
- **POV**：雨泠（第一人称「我」）
- **时间与地点**：半年后初秋傍晚；罗斯韦尔公爵领西南边界商镇「灰榆镇」（老车行 → 橡木桶酒馆 → 老松木客栈）
- **出场角色**：雨泠、车行老掌柜、退役低阶斗气军士巴顿、老车夫、白蔷薇重甲巡官
- **核心推进**：半年蛰伏学字攒盘缠确立西行「落日自由港」目标 → 干净反制敲诈地痞展示低负荷拆招掌控力 → 酒馆突发白蔷薇封城令与五百金朗“寻恩告示”并得知伊薇特亲临北门驿馆 → 折返客栈准备夜逃却听见门外叩门声。
- **章末钩子**：刚扣紧行囊准备推开后窗翻墙，走廊木板传来沉稳靴声，门外响起两声不急不缓的礼貌叩门声。
