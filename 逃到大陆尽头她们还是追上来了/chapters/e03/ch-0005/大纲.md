# 第 05 章：鸟笼里的体面晚餐

- **所属事件**：E03（E03-02）
- **POV**：雨泠（第一人称「我」）→ 尾段 `◆　◆　◆` 切入伊薇特第三人称有限视角
- **时间与地点**：灰榆镇北门驿馆临时公爵行邸（庭院 → 二楼长厅）
- **出场角色**：雨泠、伊薇特·冯·罗斯韦尔、近卫队长布兰德
- **核心推进**：雨泠勘测行邸防线，惊觉伊薇特专门针对他半年前拆银桩的手法改用了双环警讯阵 → 烛光晚宴上伊薇特点破他西行落日自由港的打算，抛出华美南翼庄园的体面鸟笼 → 雨泠正面硬刚撕破礼貌假面，伊薇特吐露深埋骨髓的执念 → 外院突发爆破，叛党残余联合暗流夜袭驿馆，切伊薇特视角看雨泠半步未退挡在窗前扫视战局。
- **章末钩子**：伊薇特看着火光里皱眉盯紧敌阵破绽、半步未逃的雨泠背影，眼底执念彻底烧亮：「嘴上总说着最怕麻烦，真遇上死局，你还是第一时间站到了我身前。」
