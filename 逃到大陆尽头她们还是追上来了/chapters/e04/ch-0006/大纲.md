# 第 06 章：火光拆阵与二度离去（第一卷终）

- **所属事件**：E04（E04-01）
- **POV**：雨泠（第一人称「我」）→ 中后段 `◆　◆　◆` 切伊薇特视角 → 尾段 `◇　◇　◇` 切回雨泠卷末钩子
- **时间与地点**：灰榆镇北门驿馆 → 两日后白昼圣堂边陲「白杨镇」
- **出场角色**：雨泠、伊薇特·冯·罗斯韦尔、近卫队长布兰德、叛党死士头目、浅金长发少女（艾琳娜剪影）
- **核心推进**：雨泠与伊薇特默契配合击溃赤红破魔钉杀阵 → 趁乱摸至西南豁口脱身，临走回身弹石替她砸偏淬毒暗弩后翻墙遁入圣堂地界 → 切伊薇特视角，她拔出毒箭彻底焊死执念，向圣堂递信跨领追夫 → 两日后雨泠踏入白杨镇，撞见高墙礼拜堂铁门内被银链束腕的浅金发少女，开启第二卷。
- **章末钩子**：礼拜堂铁门合拢前，那名腕绕细银链的浅金长发少女隔雨回头望进雨泠眼里，雨泠骂了句见鬼，脚步却又停住了。
