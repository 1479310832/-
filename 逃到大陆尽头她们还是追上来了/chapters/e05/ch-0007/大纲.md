# 第 07 章：铁门、银链与不该管的事

- **所属事件**：E05（E05-01）
- **POV**：雨泠（第一人称「我」）
- **时间与地点**：白昼圣堂东北边陲「白杨镇」（杂货旅店 → 半夜镇北旧礼拜堂地下祈祷室）
- **出场角色**：雨泠、艾琳娜、旅店老板娘、边境主教西蒙、两名白袍执事
- **核心推进**：雨泠强行压下管闲事的念头去住店买粮，报词音 `Rain` 被老板娘记成「瑞恩」，听闻礼拜堂圣女候补因查假账遭西蒙主教借长老会『临时禁制令』反咬羁押候审 → 半夜瞥见灰铜铃黑篷车驶上北坡礼拜堂，为防西行干道有诈潜入探查，撞破西蒙欲用灰铜铃秘药『静默苦露』伪造艾琳娜『神恩弃绝』以防明早当庭揭发异端交易 → 地下忏悔室灭灯打晕两名欲灌药的执事，艾琳娜平静道出早知他会来 → 拆锁时发现『净音秘银链』直连头顶大铜钟，门外传来西蒙折返脚步声。
- **章末钩子**：银链符文直连钟楼铜索，蛮力扯断必惊动全镇护卫，而走廊石阶上西蒙主教折返查锁的脚步声已近在咫尺。
