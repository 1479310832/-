# 第 09 章：免检的哨卡与过于温柔的宿屋

- **所属事件**：E06（E06-01）
- **POV**：雨泠（第一人称「我」）
- **时间与地点**：逃离白杨镇五日后午后至午夜 · 白昼圣堂东腹枢纽『风铃驿镇』（城门哨卡 → 冒险者公会公告板 → 『白鸽亭』宿屋食堂 → 商业公会马车站 → 镇西柳溪石桥）
- **出场角色**：雨泠、风铃驿镇守门神官与持簿修女、『白鸽亭』看板娘、马车站售票员、灰铜铃黑袍余党
- **核心推进**：雨泠不留姓名混入风铃驿镇，发现公会公告板毫无通缉令，但城门骑士与持簿修女瞥见他黑发后反常免检放行 → 在『白鸽亭』花两枚铜币喝热汤歇脚却被看板娘借赐福庆典免单奉上热食与二楼安静单间，傍晚去商业公会买偏南支线车票又被告知“修桥封路、唯独去大教区首府樟木城的软座马车免费送票” → 现代防诈直觉拉满的雨泠夜伏露台浅开【断点解构】，抓包看板娘与修道院见习修女放飞附魔传讯白鸽，彻底看穿艾琳娜覆盖全教区的“温柔引流软网” → 半夜摸往镇西柳溪石桥准备翻山脱网，却撞见两名灰铜铃余党正在桥墩下埋设引诱魔狼潮的『腥红诱魔石』。
- **章末钩子**：一旦魔狼群夜袭驿镇，教廷驻军必封山十天半月，雨泠刚要绕行却见桥洞下亮起即将激发的妖异红光。
