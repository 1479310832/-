# 第 10 章：修道院白鸽与跨境的白蔷薇

- **所属事件**：E06（E06-02）
- **POV**：雨泠（第一人称「我」）→ 中后段 `◆　◆　◆` 切入艾琳娜第三人称有限视角 → 尾段切回雨泠第一人称
- **时间与地点**：午夜风铃驿镇柳溪石桥与『白鸽亭』后窗 → 次日暴雨黄昏『樟木城』外西渡口 → 艾琳娜圣女巡礼马车 → 城南白樟修道院旧侧廊告解室
- **出场角色**：雨泠、两名灰铜铃黑袍余党、白蔷薇伪装商队精锐、艾琳娜、心腹随侍修女
- **核心推进**：雨泠以【断点解构】看穿桥头修桥脚手架承重木楔断点，一脚踹脱木栓引发半车修桥碎石滑坡，直接砸灭黑袍人提灯并将未激发的『腥红诱魔石』连筐冲入激流带往下游瀑布，甩石击晕望风余党静音拆局 → 临走前特意摸回『白鸽亭』在枕上按落两枚饭钱铜币，并在北门买蓑衣设疑兵，连夜沿河滩疾行直插樟木城外西渡口 → 次日暴雨突至，西渡口竟被伪装成银矿商队的白蔷薇重甲精锐包场封锁（伊薇特识破教廷敷衍跨国截胡！） → 切艾琳娜马车视角：把雨泠留下的两枚枕边铜币摆在圣典便条旁温柔浅笑，算准讨厌刀兵的雨泠避开渡口后必走城南无人看守的白樟修道院旧侧廊 → 切回雨泠：冒雨潜入城南旧修道院空荡荡的小礼拜堂告解室喘息拧帽，身旁雕花木格窗却无声滑开，传来艾琳娜温柔含笑的低语。
- **章末钩子**：隔着告解室薄薄一层雕花木格窗，白纱下的圣女轻声问候：「迷途淋雨的旅人先生，昨晚的白麦面包钱我已经收到了，怎么今晚又急着躲我呢？」
