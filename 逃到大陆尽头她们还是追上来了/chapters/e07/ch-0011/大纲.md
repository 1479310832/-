# 第 11 章：隔板后的告解与两枚铜币

- **所属事件**：E07（E07-01）
- **POV**：全程雨泠第一人称（「我」）
- **时间与地点**：秋日暴雨入夜，樟木城南墙外围『白樟修道院旧侧廊』附属小礼拜堂（木制双联告解室内 → 礼拜堂昏黄油灯长椅间 → 祭坛白纱帷幕前）
- **出场角色**：雨泠、艾琳娜、廊外望风的年轻随侍修女、门外通报的布兰德（声音出场）
- **核心推进**：雕花木格窗滑开后，雨泠压下惊骇浅层凝视礼拜堂，发现殿内虽无刀兵护卫，侧门铜环却连着一缕系在艾琳娜指尖『净音秘银链』断环上的纯白圣光丝 → 雨泠扣回湿毡帽压粗嗓音装作避雨脚夫试探，艾琳娜却顺着窗底窄槽轻轻推来『白鸽亭』枕上的两枚宿钱铜币，隔板温柔点破他撬断银链、冲走石桥脏东西与翻窗留宿钱的底细 → 雨泠推回铜币走出隔间退开三步，当面怼穿她把三座教区变成温柔引流滑梯的把戏，声明写下『别再回那个鸟笼』绝非为了自己钻进圣城新笼子 → 艾琳娜步出隔间，从圣典夹层抽出伊薇特致东境大主教悬赏三座富银矿五年什一税的白蔷薇公函，温柔挑明外头全是世俗重弩，唯有她的圣女巡礼车驾能护他西行 → 雨泠断然拒乘并按住短刀欲挑断圣光丝翻南墙脱身，院外暴雨中骤传重车轰鸣，随侍修女推门急报罗斯韦尔老骑士长布兰德已率三辆伪装银矿马车堵死正拱门、并派骑手举强光提灯包抄南墙外巷求见圣女！
- **章末钩子**：前有圣女指捻银链撩开祭坛侧后遮掩暗门的纯白帷幕，外院正门与南墙皆被白蔷薇精锐封死，艾琳娜在摇曳灯影里温柔反问：「看来罗斯韦尔家的猎犬鼻子比我想的还要灵呢……旅人先生，现在您还要拔刀往外闯吗？」
