# 第 13 章：暗窖鼠影与掀翻的棋盘

- **所属事件**：E08（E08-01）
- **POV**：全程雨泠第一人称（「我」）
- **时间与地点**：秋日后半夜两点至破晓前，樟木城南『白樟修道院旧侧廊』更衣内室 → 祭坛下废弃排洪暗窖 → 西南城墙外芦苇河沟与荒野高坡
- **出场角色**：雨泠、三名灰铜铃取货余党（含刀疤头目）、艾琳娜、布兰德（及白蔷薇重弩护卫）
- **核心推进**：后半夜两点，三名灰铜铃余党自排洪渠摸上暗窖石台，头目命两人先抬第一箱『爆裂魔石』走水路出城，自己拆开第二箱改接纵向铜线，欲炸塌头顶圣像祭坛害死圣女并嫁祸门外扎营的罗斯韦尔商队 → 雨泠不忍艾琳娜被疯子炸死，抽回门缝剥皮短刀（以旧木片替补抵门），趁搬货党走远撬开活板门滑入暗窖，一记刀柄重击放翻捆死留守头目 → 强忍太阳穴刺痛剪断冲向祭坛的纵向主铜丝，将六枚爆裂魔石回路改向并联至西侧无人废廊裂墙与排洪渠蓄水挡墙，拨定十五秒延时 → 临退入暗渠前抠下半块废魔石弹响前殿圣光网示警，冲跑进更衣室的艾琳娜喊出「退回圣像前头去！西侧要炸了！」后扎入排洪渠 → 定向爆炸轰塌西侧废墙并冲烂尽头锈蚀熟铁水栅，把前头两名搬货余党掀出缺口撞上破门强突的布兰德重弩队，圣堂白光、军用连弩与异端混作一团 → 雨泠顺激流跌出城外芦苇河沟，撕碎泡软的暗窖简图，爬上高坡却见原本打算偷渡的上游浅滩与正西平原干道均已燃起封路烽火、巡逻船封死白浪河面。
- **章末钩子**：水陆平原退路被女公爵与圣女彻底锁死，雨泠盯向地图左下角标着『异端魔境，禁行』的涂黑区，迎着西南地平线上终年不散的诡异紫金色雾霭，扣紧旧毡帽拐上了通往『永暮森域』的荒野古道。
