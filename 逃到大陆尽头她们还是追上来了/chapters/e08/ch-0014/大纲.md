# 第 14 章：双网余烬与永暮之森（第二卷终）

- **所属事件**：E08（E08-02 · 第二卷收官章）
- **POV**：雨泠（第一人称「我」）→ 中段 `◆　◆　◆` 切艾琳娜第三人称有限视角 → 尾段 `◇　◇　◇` 切回雨泠第一人称卷末钩子
- **时间与地点**：破晓前『永暮森域』外围残破界碑 → 同日清晨樟木城南『白樟修道院旧侧廊』废墟与更衣内室 → 两日后『永暮森域』外围腹地古石环
- **出场角色**：雨泠、艾琳娜、布兰德、圣城随军工匠神官、白昼异端审问官与雇佣猎巫队、孤高魔女维奥莱塔（卷末初登场）
- **核心推进**：雨泠连夜奔至教廷与『永暮森域』交界的劈裂石碑下喘息，摸出内袋无油旧打火机空打火星确认完好，复盘昨夜露出的十五秒改回路底牌必令两位掌权者更想抓他当破阵工具，遂啃过冷硬黑麦饼，顶着树梢古怪黑鸦的注视跨过界碑踏入紫金色迷雾古林 → 切艾琳娜视角：清晨修道院废墟中，灰铜铃三名余党悉数落网，布兰德勘出西南泥靴印前来辞行，点破暗窖引信被人刻意剪改护住祭坛，并透出伊薇特已亲率白蔷薇主力西进；艾琳娜独返更衣内室，看着门缝下防她反锁的旧木片与暗窖改向焦痕，端起桌上凉透的白瓷杯蜂蜜水饮尽，下令圣女车驾改道西南森域边境迎候 → 切回两日后的雨泠：沿森域外围古道疾行庆幸耳根清净，前方古石环骤爆秘术雷光与封魔锁链铮鸣，教廷异端审问官正联合世俗重甲猎巫队以六根封魔桩围杀重伤的黑紫卷发魔女（维奥莱塔）；濒临绝境的少女左手欲捏碎秘术晶核同归于尽，琥珀色眼睛穿过纷飞鸦羽撞进树后雨泠眼底。
- **章末钩子**：猎巫阵左侧那根被老树根拱歪半寸的封魔铁桩死穴清晰跳进视野，雨泠摸着胸口冰凉的无油打火机，脚步再度钉死在腐叶地上，低声痛骂怎么钻进深山老林都能撞上自爆现场（第二卷完）。
