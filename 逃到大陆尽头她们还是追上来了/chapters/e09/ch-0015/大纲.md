# 第 15 章：碎桩、血契与走反的雾路

- **所属事件**：E09（E09-01 · 第三卷开篇）
- **POV**：全程雨泠第一人称（「我」）
- **时间与地点**：『永暮森域』外围北侧古道黑杉陡坡与古石环 → 半公里外藤瀑玄武岩裂窟 → 三个小时后的森域内圈黑曜石古阶
- **出场角色**：雨泠、维奥莱塔、两名白昼圣堂异端审问官与八名雇佣死士
- **核心推进**：石阶上的异端审问官察觉维奥莱塔视线飘向北坡，喝令两名死士提剑搜坡；退路被堵的雨泠朝维奥莱塔比出低头手势，踹落树旁二十多斤棱角青石砸塌第三根封魔铁桩下的腐朽空心老杉树根 → 六芒禁魔光幕逆流反噬炸飞两名审问官，维奥莱塔收起自爆晶核、震碎裂纹黑曜石短杖掀开紫黑浓雾；远处北道传来审问局援军铜哨与猎犬吠声，为防猎犬顺滚石泥印追查自己，雨泠滑下陡坡拎住失血软倒的维奥莱塔披风厚领，蹚溪断味钻入藤瀑后的玄武岩裂窟 → 雨泠看穿她左肋倒刺破魔短矢卡在披风内衬的秘银护肋暗扣上，用剥皮短刀刀尖挑开簧片卸除短矢，丢回止血白藓粉与绷带背身避嫌；维奥莱塔划出暗紫符纹要求他报真名立『双生鸦契』抵命，多疑的雨泠严词拒签 → 寒毒与林瘴侵袭下维奥莱塔魔力紊乱点不燃『驱瘴安魂香绒』，雨泠摸出内袋里早已干油的**旧金属打火机**擦出火星引燃香绒，避开她的手将打火机搁在石边抵账，趁她昏睡果断溜走 → 为绕开北侧古道上的审问局搜山大队，雨泠往南侧密林迂回疾行三个钟头，却发现脚下腐叶变成抬升的黑曜石古阶、树干四面青苔等厚、溪水逆流打转。
- **章末钩子**：雨泠头皮发麻猛然回头，上千只暗金眼珠的紫黑使魔乌鸦已无声落满身后树冠封死退路，正前方浓雾裂开浮现悬挂倒月鸦徽的黑石尖塔——摸黑狂奔三个钟头，竟直接跑进了魔女议会的老巢大门口！
