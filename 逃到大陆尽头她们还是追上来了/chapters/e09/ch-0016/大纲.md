# 第 16 章：鸦群尖塔与咔哒作响的火苗

- **所属事件**：E09（E09-02）
- **POV**：雨泠（第一人称「我」）→ 尾段 `◆　◆　◆` 切入艾琳娜第三人称有限视角
- **时间与地点**：『永暮森域』北境断崖双头黑鸦黑曜石尖塔门前石阶与崖边值守石屋 → 森域外围北侧古石环猎巫废墟
- **出场角色**：雨泠、维奥莱塔、艾琳娜、护教圣殿骑士队长、被扣押的白昼异端审问官
- **核心推进**：雨泠在黑曜石古阶上看穿发光紫苔连着塔顶幽紫长明灯的折射回路，闭眼欲踩石阶排水盲槽倒退脱身，头顶尖塔二楼悬廊石栏后却响起熟悉的「咔哒」擦火声 → 已包扎伤处换上黑金高领魔女袍的维奥莱塔倚栏俯视，指间那枚旧金属打火机已被灌入『冥烛燃灵油』燃起幽紫冷火；她缓步下至五步高台，点破打火机绝非四国造物，搬出夜想魔女等价清算规矩细数破阵、拔箭、赠火器三笔旧账 → 多疑的雨泠认定她想扣留自己研究无魔力破阵眼力与异界造物，按刀拒入尖塔要求指路两清；东北外围突传三记白昼圣堂护教涤罪钟声，侦察黑鸦回报新任圣女艾琳娜已缴了异端审问局分队的械并驻车北道寻访“黑发旅人”，外围河谷另有白蔷薇骑兵游弋 → 进退两难下，维奥莱塔霸道宣布结清旧账前谁也别想从她森域抢人；雨泠拒进封闭主塔，只选崖边透风值守石屋暂歇，暗中锁死塔顶长明灯底部的换气晶槽节点 → 切艾琳娜视角：她在古石环废墟勘见被滚石砸塌树根的第三根封魔铁桩，一眼认出雨泠招牌拆阵手法，得知他竟顺手救走了夜想席位魔女维奥莱塔，指间秘银断链收紧，命护教骑士封锁北境出口。
- **章末钩子**：艾琳娜立在被圣光逼退的紫金雾墙前，盯着那截崩歪的封魔铁桩温和低语——连她递出的蜂蜜水都不肯喝一口的先生，进山第一天竟又去拆了异端魔女的锁链（三方修罗场火药桶正式引燃！）。
