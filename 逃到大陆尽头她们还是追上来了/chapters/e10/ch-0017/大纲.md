# 第 17 章：夜鸦庭院与白羽拜帖

- **所属事件**：E10（E10-01）
- **POV**：全程雨泠第一人称（「我」）
- **时间与地点**：『永暮森域』北境黑石尖塔『夜鸦庭院』与矮石屋 → 断崖黑杉岩台与『雾界石拱桥』
- **出场角色**：雨泠、维奥莱塔、艾琳娜、灰袍外院执事女巫、见习魔女、银甲护教圣殿骑士
- **核心推进**：破晓时分东北天际刺起『白昼净光圣炬』光柱，雨泠步入『夜鸦庭院』勘查后山排水石涧退路；维奥莱塔携透明水晶瓶泉水、熏鹿肉与『羊皮森域舆图』前来，雨泠看穿舆图路线串过三座鸦哨且图角嵌有连接塔顶长明灯的紫晶共振水纹 → 见习魔女与腰挂药剂钥匙串的灰袍执事女巫赶来禀报：圣女艾琳娜已抵『雾界石拱桥』呈递双印拜帖讨人，且西南三公里『沉木谷』三只巡夜乌鸦失联（雨泠留意到灰袍女巫鞋跟硫磺红泥与焦土味） → 维奥莱塔收好打火机与地图，留两只巨鸦盯门赴桥头交涉；雨泠在石屋挂牌落栓顶上橡木箱制造假象，从北侧窄窗翻上四十米高的黑杉岩台俯瞰偷听 → 桥头艾琳娜与维奥莱塔围绕雨泠展开首次正面言辞与魔力交锋（各自认出对方身上的破魔箭拔除手法与『净音秘银链』撬痕，圣光与咒雾对撞） → 西南『沉木谷』源质窟突遭灰铜铃爆破震动，灰袍内鬼女巫往主塔后崖副风道塞入蚀脉灰铅铁楔令长明灯明灭闪烁，并携涂毒吹箭筒与麻痹毒液摸至空石屋北窗外欲杀人灭口。
- **章末钩子**：桥头双女同时察觉西南闷爆与塔顶长明灯异状，而趴在十余米外岩棱阴影后的雨泠看清暴露间隙的塔顶六角水晶换气卡槽，拇指缓缓推开剥皮短刀准备先手擒贼破笼！
