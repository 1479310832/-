# 第 18 章：熄灯、鸦潮与断风西口

- **所属事件**：E10（E10-02 · E10 完结章）
- **POV**：雨泠（第一人称「我」）→ 尾段 `◆　◆　◆` 切入维奥莱塔第三人称有限视角
- **时间与地点**：『夜鸦庭院』与黑石尖塔后崖 → 『废矿暗涧』与西出口『断风山口』 → 『沉木谷』与归塔庭院
- **出场角色**：雨泠、维奥莱塔、灰袍外院执事女巫、见习魔女、灰铜铃盗掘残党、白蔷薇重装哨骑
- **核心推进**：趁守门巨鸦惊飞张望，雨泠从岩棱滑落三秒放翻北窗外的灰袍执事女巫，搜出塞棉旧灰铜铃铛、风道检修铜钥匙串与无诱导暗纹的防水油纸撤离草图（标明『废矿暗涧』、『断风山口』及西部枢纽重镇『银轮城』） → 雨泠看穿灰铜铃堵死副风道企图引倒灌浊源质五分钟内炸毁尖塔蓄能池的毒计，用检修钥匙打开后崖主风道竖井铁篦，拔出副风道灰铅铁楔泄压救塔并拉起浓白雾墙，同时借竖井强劲上升气流将灰铅铁楔夹黑曜碎石冲上三十米塔顶，精准卡死『六角水晶换气卡槽』熄灭幽紫长明灯，震碎五公里折光雾障 → 雨泠把灰袍内鬼捆在庭院石桌旁摆齐铁证，摘下门环上的『双头黑鸦黑曜石腰牌』挂回内鬼腕上宣告两清，钻入『废矿暗涧』至『断风山口』 → 巧借两名被鸦群追啄逃出北坡的灰铜铃残党引开白蔷薇连弩哨卡，顺南侧排水断沟穿出防线遥望『银轮城』 → 切维奥莱塔视角：她在沉木谷剿灭灰铜铃盗掘队封住源质裂口后归塔，面对空屋北窗、内鬼腕上腰牌与被卡死的长明灯气极反笑（按亮金属打火机记下“五笔人情加一笔毁灯赔偿账”），得知艾琳娜与伊薇特本阵双双汇聚『银轮城』，亲点轻骑鸦群抄旧猎道直扑『银轮城』。
- **章末钩子**：掌心幽紫冷火跳动，漫天黑鸦遮蔽日光——公爵、圣女与席位魔女三路人马已沿着商道向同一座十字咽喉『银轮城』合拢！
