# 第 19 章：银轮马市与桥头旧物

- **所属事件**：E11（E11-01 · 全书中点修罗场开篇）
- **POV**：雨泠（第一人称「我」全程紧贴）
- **时间与地点**：入林第 3 天黄昏；『银轮城』南郊纤夫集市与『南水门』 → 『西河马市』及粮坊后巷 → 『银轮锁桥』东堍『南轮机括石廊』与对岸『临河迎宾露台』
- **出场角色**：雨泠、伊薇特·冯·罗斯韦尔、艾琳娜、维奥莱塔、布兰德、商业评议会执事、私槽马贩
- **核心推进**：黄昏时分雨泠抵『银轮城』南郊，花四枚铜币购粗褐帆布短罩衫与麻布头巾遮掩黑发，将风衣、油纸草图与黄铜检修钥匙串压入包底，顺纤夫卸货人流混入中立自治的『南水门』 → 赴『西河马市』欲用九枚银朗买二手轻骑趁暮钟前过河，撞上伊薇特借罗斯韦尔大商会包销全城现货轻骑、散客须赴马政公证处摘帽实名候审一小时的阳谋；退入后巷又遇私槽马贩兜售“八枚银朗免路引快马”，雨泠从马贩靴筒内侧铁镫磨痕与巷尾茶摊便衣护卫手茧识破布兰德的诱捕桩，借故取钱从香料库侧门脱身 → 果断弃马改赴唯一西渡咽喉『银轮锁桥』准备徒步混桥，见布兰德守在桥东税卡，遂闪入挂有『南轮机括廊·闲人免入』木牌的水雾石廊中层百叶窗后观察桥底栈道 → 东街伊薇特仪仗专驾与北街艾琳娜四国免检素白专驾同时抵近桥东广场，经商业评议会执事引至十米外的半敞『临河迎宾露台』首次当面交锋 → 伊薇特重提十日前『三座富银矿五年什一税协寻公函』拆穿艾琳娜敷衍回信实则藏人，艾琳娜以『鸟笼』回刺并随河风露出圣典扉页那半张硬笔麦饼纸便条；伊薇特认出与灰榆镇工坊账册一致的笔锋，冷意大盛拨开鎏金扁匣亮出带银灰金属拉链的深灰连帽卫衣与半块迎宾馆断墙青苔碎砖（令石廊内的雨泠误以为她连碎砖都留作追查破阵者的物证） → 霜寒魔力与纯白圣光将石桌冻裂对峙之际，数十只使魔乌鸦自暮云俯冲落满桥链，对岸税关石楼钟塔飞檐响起清脆「咔哒」声，维奥莱塔按亮旧金属打火机幽紫冷火现身讨要拔箭贴身火器与今日毁灯之账！
- **章末钩子**：深灰连帽卫衣、麦饼纸便条与燃着幽紫冷火的旧金属打火机在『银轮锁桥』桥头首次齐聚，水雾石廊里的雨泠被三位债主同时堵死在唯一西渡通道前！
