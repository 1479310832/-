# 第 20 章：幽紫火苗与三方死结

- **所属事件**：E11（E11-02 · E11 完结章 / 全书中点修罗场高潮）
- **POV**：雨泠（第一人称「我」）→ 尾段 `◆　◆　◆` 切入伊薇特第三人称有限视角
- **时间与地点**：入林第 3 天日落暮钟时分；『银轮锁桥』东堍『南轮机括廊』与对岸『临河迎宾露台』 → 东岸谷仓卸货滑索与内城石板夜巷 → 落闸后的『南轮机括廊』与桥东广场
- **出场角色**：雨泠、伊薇特·冯·罗斯韦尔、艾琳娜、维奥莱塔、布兰德、商业评议会执事与护桥卫队
- **核心推进**：钟塔飞檐上维奥莱塔手中的旧金属打火机与露台上的深灰连帽卫衣、麦饼纸便条三物同场，三位女主瞬间拼合出那个“绝境救人、拒收契约重酬、丢下随身旧物秒溜”的黑发惯犯全貌 → 唇枪舌剑间维奥莱塔合上打火机一语点破“急着去西海岸的正主此刻多半就躲在暮钟落闸前的桥头附近看戏”，三方瞬间铺开搜捕网，却因谁也绝不容许另外两人抢先带走雨泠而彼此拆台（伊薇特凝冰雾风墙撞偏俯冲南岸的使魔鸦群，艾琳娜命四国免检素白专驾斜移三步堵死白蔷薇重弩队冲向石廊铁门的路线，维奥莱塔驱巨鸦抓散探向引水槽的纯白圣光丝） → 雨泠在『南轮机括廊』内看穿三方互防留出的十秒衔接死角与水轮配重棘轮结构，忍着太阳穴刺痛取出黑石尖塔顺来的黄铜检修钥匙串，挑两把厚实铜匙塞死副泄洪闸止退卡爪根部的回落限位槽，在第一记暮钟震响瞬间踹脱应急泄压木杠 → 副闸过载洞开令百米『南银轮』掀起二十米高的狂暴白浪水幕席卷桥头、触发防洪铜铃警报并引来商业评议会护桥卫队；雨泠卸下石廊南侧双耳铁滑轮，借水幕遮蔽顺滑索疾滑三十米落入东岸谷仓排洪暗沟，弃掉湿罩衫翻入内城夜巷 → 听见『银轮锁桥』铁闸彻底落死，雨泠在屋檐下摊开手绘地图，将视线从断绝的西行大道转向正北偏西绕过峡谷通往『赤铁边塞』的险峻军道 → 切伊薇特视角：三女步入空荡的『南轮机括廊』，维奥莱塔从止退卡爪限位槽里夹出两把自家尖塔的黄铜风道钥匙气极反笑，艾琳娜注视窗沿干指印，伊薇特合上鎏金扁匣抚平白丝手套，三方达成封死『银轮城』四门出口的无声死结。
- **章末钩子**：跨河铁闸彻底落锁，白蔷薇骑队、护教圣殿骑士与夜想使魔鸦群破天荒分守四门——整座『银轮城』化作三把锁扣死的巨大棋盘！
