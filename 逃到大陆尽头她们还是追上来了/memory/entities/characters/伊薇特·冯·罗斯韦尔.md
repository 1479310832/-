# 伊薇特·冯·罗斯韦尔

## 基础信息
- **身份 / 阵营**：圣瓦伦王国 · 罗斯韦尔公爵领（白蔷薇家）唯一正统继承人（后铁血继位为女公爵）
- **外貌速查**：银灰长发、冷翡翠眼眸、身姿挺拔克制；右手习惯戴一只纯白丝手套（遮掩当年政变雨夜为抓紧剑柄留下的细疤，也避免沾染凡俗尘埃）。
- **核心性格**：极度理智、体面、深谙权谋与礼仪，哪怕怒极或偏执到极致，说话也始终轻声细语、滴水不漏；唯有在雨泠面前，那层冷傲贵族面具下会渗出令人脊背发凉的占有欲与隐秘委屈。

## 记忆点（银魂法）
- **视觉记忆点**：冷翡翠眼眸 + 右手纯白丝手套 + 贴身匣中叠得一尘不染的那件深色现代连帽外套。
- **行为记忆点**：每次即将收网堵死雨泠退路前，都会不紧不慢摘下或抚平右手白手套的褶皱，微笑着替他算“旧账”。
- **语言记忆点（口吻/口癖）**：极端礼貌、暗藏窒息压迫的贵族潜台词（「救命之恩尚未结算，阁下不告而别，可是瞧不上罗斯韦尔家的诚意？」）。
- **反差记忆点**：在议政厅里三言两语便能决定叛党贵族的生死，冷血果决；私下却会一遍遍摩挲一件异界廉价布料外套的袖口，只因那是绝境雨夜里唯一不带任何交易筹码披在她肩上的温度。

## 执念与病娇形态
- **被雨泠救/帮的契机**：老罗斯韦尔公爵暴毙当夜，旁系联合死士在行宫雨林设伏截杀，连她信任的贴身骑士都临阵倒戈；刚身穿落地的雨泠撞进死局，凭【断点解构】拆掉包围杀阵带她突围，替她包扎、把自己的深色现代外套披在她身上，留下半句别扭叮嘱「天亮前别睡死过去，顺着泥路往主道走」后便趁拂晓溜走。
- **为什么对他产生偏执执念**：从小长在利益交换的公爵府，她从未见过「拼死救她、披上外套、却连名字与酬劳都不肯要」的人；他一走了之的漫不经心，在她心里反而化成了最致命的失控——她绝不允许世上唯一真正属于自己的光，就这么消失在人海里。
- **占有的具体方式 & 千里追夫手段**：铁血清算政变执掌大权后，将白蔷薇商会驿站、行省关卡与贵族画像网全部铺开，表面优雅从容、步步封城锁路，誓要把雨泠“体面而彻底地请回罗斯韦尔领”。
- **底线确认**：绝对纯爱，情感与身心唯属雨泠一人。

## 行为底层逻辑
- **绝不妥协的事**：绝不再将后背交给任何背叛者；绝不再让雨泠从自己视线里第二次溜走。
- **初期认知边界**：初遇时只知道他是异域打扮、黑发黑眼、毫无魔力却能诡异拆招的神秘青年，甚至一度不知他的全名（雨泠随口只扔了个“雨”字或假名，待事件画布细化）。
