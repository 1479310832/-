# 布兰德

## 基础信息
- **身份 / 阵营**：圣瓦伦王国 · 罗斯韦尔公爵领近卫骑士长（跨境执行任务时化用商号头衔「罗斯韦尔商会总管」）
- **外貌与仪态**：年过半百、双臂健全魁梧、鬓角微霜，举止恪守大贵族家臣礼法，眼神老辣冷峻，说话中气十足带浓重军阵压迫感。
- **剧情定位**：伊薇特手中最可靠的世俗追捕执行官。东林雨夜率亲卫救驾迎回伊薇特；灰榆镇随同封城并在迎宾馆夜袭中率盾卫反扑；第二卷奉命率领藏有十二连发重弩的白蔷薇精锐伪装成跨国银矿商队，先锁死白浪西渡口，再顺河岸痕迹与素车动向逼近樟木城南白樟修道院旧侧廊。
