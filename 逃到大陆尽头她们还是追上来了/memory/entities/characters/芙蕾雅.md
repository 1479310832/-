# 芙蕾雅

## 基础信息
- **身份 / 阵营**：北境铁壁骑士团 · 团长
- **外貌速查**：酒红高马尾、灰蓝利眼、银灰轻甲外罩暗红残破骑士披风。
- **核心性格**：原则至上、克制守礼、铁面刚直；向来公私分明，却唯独在雨泠身上把“守护、规矩与私人占有”彻底拧成了一股绳。

## 记忆点（银魂法）
- **视觉记忆点**：腰间礼仪长剑旁，始终多挂着一柄格格不入的**半截缺口短剑**（雨泠劈开突围口后遗落之物）。
- **行为记忆点**：堵住雨泠时会极其规范地行骑士礼、掏出盖满火漆的公文，下一秒却用公事公办的冷硬语气宣布“即日起由本人贴身看管”。
- **语言记忆点（口吻/口癖）**：冷静、条理分明、不容置喙的文书式潜台词（「依据边防条例，无籍异乡人需接受长期核查——地点由我定，期限为终身。」）。
- **反差记忆点**：战场与军议上铁血无情，面对雨泠别扭的回应时耳尖会微微泛红，却绝不肯松开扣住他手腕的力道。

## 执念与病娇形态
- **被雨泠救/帮的契机**：遭朝堂权贵出卖被困边塞孤城、弹尽粮绝之际，路过的雨泠嫌城破会堵死自己出境的官道，顺手用【断点解构】拆掉敌军攻城魔导炮并劈开突围缺口，留下一句「活下来再讲规矩」便翻墙消失。
- **占有的具体方式 & 千里追夫手段**：平生首次公器私用，以「核查边防重大立功且无籍贯之异乡人」为由亲率亲卫跨省追查，专克雨泠的官道伪装与城防通关。
- **底线确认**：绝对纯爱，情感与身心唯属雨泠一人。
