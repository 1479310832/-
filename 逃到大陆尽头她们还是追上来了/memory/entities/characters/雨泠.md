# 雨泠

## 基础信息
- **身份**：身穿至异世界的现代男性青年（初登场约 20~22 岁）
- **名字与称呼设定**：
  - **「雨泠」（内心自认的名字 / 原世界网名）**：原世界独居多年，身份证与工牌上的真名早成了冷冰冰的符号，反倒是少年时起沿用近十年的网名「雨泠」（取雨落清冷、互不打扰之意）更像他真正认领的名字。
  - **「雨」（对女主首次留下的单字假名）**：东林猎屋被伊薇特追问姓名时，因无法向中世纪贵族解释何为网名、「雨泠」二字在当地语感里又显拗口，便截掉后字随口报了单字「雨」。旁人一听拿当晚的天气当名字，皆知是敷衍的假名，唯独伊薇特偏执地将「雨」当作专属称呼记死。
  - **「Rain → 瑞恩」（外人偶发听岔称呼，不作全文主称呼）**：后来在边城混饭吃时，报单字「雨」总被掌柜与路人笑话是糊弄鬼的假名，他嫌烦便随口换用原世界的英文词音 `Rain` 应付，被本地人顺耳听岔成圣瓦伦常见的平民男名「瑞恩」。仅在镇民、掌柜等外人交谈时偶尔出现，绝不替代全文。
- **外貌速查**：黑发黑眸（在金银褐发为主的西幻大陆辨识度极高，后期常压低兜帽或微做易容）；身材清瘦利落，眼神偏冷淡，神情总带几分懒得应付场面的克制。
- **核心性格**：性格别扭、嘴硬心软，骨子里却是**高度多疑警惕**的异界无根者。遇到荒唐死局过不去良心关见死必救，但身为一介毫无魔力却能看穿一切法阵禁制死穴的黑户，他对掌权者的超额善意极度缺乏信任——大局上总怀疑女主们大动干戈留他是盯上了他的破阵底牌（想圈养当专属破阵工具或灭口保密），绝不自作多情；日常交涉时更习惯暗查茶水、门闩、马车铭文有无后手，一旦心头生出半分动摇便立刻拿理性多疑掐灭，干完事趁乱抽身。

## 记忆点（银魂法）
- **视觉记忆点**：异界罕见的黑发黑眼 + 常习惯压低的旅行兜帽（以及因接连随手留给被救女主而越来越少的现代随身旧物）。
- **行为记忆点**：一边嘴硬救人，一边在面对女主的温柔招待时习惯性做“防诈检查”（扫门栓活扣、瞄茶杯有无药渣、怀疑车厢刻了禁魔阵），确认对方死不了便挑最高效的空档不告而别。
- **语言记忆点**：表面克制寡言、尽量用最短的话结束交涉；第一人称内心 OS 敏锐多疑又别扭，习惯给上位者的体面台词做“恶意潜台词翻译”（绝不油腻插科打诨，也不做机械喊着“我要回家”的跑图人机）。
- **反差记忆点**：面对杀气腾腾的死士与法阵冷静得像拆钟表；面对温柔礼貌、眼神专注的女主时偶尔心口微乱，却立刻脑补对方图谋自己的破阵眼力而如临大敌，硬生生把暧昧演成防贼拉扯。

## 行为底层逻辑
- **绝不妥协的事**：绝不对眼前明显能救下的无辜死局袖手旁观；绝不交出自由底线去赌上位者的“良心”，真被堵到墙角时也能冷静试探反将一军。
- **感情与多疑错位逻辑**：并非木头人机，能直观感受到女主们逼人的美貌与专注，但乱世见闻（贵族叔侄灭口、主教灌毒栽赃）让他不敢相信无缘无故的深情，总把她们的偏执真心误判为“笼络稀有破阵师的手段”；「去落日自由港找归途」是他防止自己心软沉溺的心理锚点，而非机械口号。
