# 雨泠

## 基础信息
- **身份**：身穿至异世界的现代男性青年（初登场约 20~22 岁）
- **名字与称呼设定**：
  - **「雨泠」（内心自认的名字 / 原世界网名）**：原世界独居多年，身份证与工牌上的真名早成了冷冰冰的符号，反倒是少年时起沿用近十年的网名「雨泠」（取雨落清冷、互不打扰之意）更像他真正认领的名字。
  - **「雨」（对女主首次留下的单字假名）**：东林猎屋被伊薇特追问姓名时，因无法向中世纪贵族解释何为网名、「雨泠」二字在当地语感里又显拗口，便截掉后字随口报了单字「雨」。旁人一听拿当晚的天气当名字，皆知是敷衍的假名，唯独伊薇特偏执地将「雨」当作专属称呼记死。
  - **「Rain → 瑞恩」（外人偶发听岔称呼，不作全文主称呼）**：后来在边城混饭吃时，报单字「雨」总被掌柜与路人笑话是糊弄鬼的假名，他嫌烦便随口换用原世界的英文词音 `Rain` 应付，被本地人顺耳听岔成圣瓦伦常见的平民男名「瑞恩」。仅在镇民、掌柜等外人交谈时偶尔出现，绝不替代全文。
- **外貌速查**：黑发黑眸（在金银褐发为主的西幻大陆辨识度极高，后期常压低兜帽或微做易容）；身材清瘦利落，眼神偏冷淡，神情总带几分懒得应付场面的克制。
- **核心性格**：性格别扭、嘴硬心软、极其讨厌人情债与隆重道谢。遇到荒唐死局或见死不救会过不去心里那道坎，但帮完人从不图回报，也不想牵扯进任何复杂关系——干完事确认对方死不了，便习惯趁夜或趁乱直接抽身跑路。

## 记忆点（银魂法）
- **视觉记忆点**：异界罕见的黑发黑眼 + 常习惯压低的旅行兜帽（以及因接连随手留给被救女主而越来越少的现代随身旧物）。
- **行为记忆点**：每次救完人处理收尾时嘴上嫌麻烦，确认对方喘过气后一定会找个最不体面但最高效的时机（天亮前、对方昏睡时、换防空档）不告而别。
- **语言记忆点**：表面克制寡言、尽量用最短的话结束交涉；第一人称内心 OS 极其敏锐别扭，擅长冷静拆解局势与自我吐槽（绝不油腻插科打诨）。
- **反差记忆点**：面对杀气腾腾的死士与法阵冷静得像拆钟表；面对温柔礼貌、眼神却锁死自己的病娇女主时，心里警铃大作、脊背发僵，嘴上却还要硬撑体面找借口开溜。

## 行为底层逻辑
- **绝不妥协的事**：绝不对眼前明显能救下的无辜死局袖手旁观；绝不向权势低头，也不做窝囊废——真被堵到退无可退时，反而会压下慌乱、直面交锋或反客为主。
- **感情态度**：并不迟钝，能清楚察觉女主们温柔礼貌下的偏执与危险，正因“察觉到了才觉得太沉重太吓人、必须先润为敬”。
- **身穿随身物清单**（待确认：外套、打火机、手表/便签等，作为女主们千里追夫的关键信物）。
