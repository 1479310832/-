# 断点解构

## 一句话核心
能像拆解精密钟表般看穿异界魔力流转、法阵节点、剑技发力链与局势破绽中的「结构断点」，以极低成本借力打力、一击拆局。（注：本书无系统面板，第 1~2 章未命名；第 3 章雨泠在马车工坊拆修轮轴榫卯半年后，自己随口给这门眼力起名『断点解构』；正文实战描写优先呈现视野褪色、红痕与节点死穴等具体视觉过程，禁止刷网游式 `【断点解构】` 技能框。）

## 运作机制
1. **魔导与阵法断点**：能直接“看见”魔法咏唱链条与仪式法阵里承重最脆弱的节点，用石子、短刃或错位干扰就能让高阶术式反噬崩解。
2. **近战发力断点**：在近身交锋中捕捉对手重心转移、呼吸换气与发力衔接的毫秒级空隙，借力卸劲或一击制敌。
3. **局势与防线盲点**：面对围捕、封城与死士杀阵，能迅速定位防线衔接处的视野与时间盲区，找到唯一脱身路线。

## 严格限制与代价（防无敌崩坏）
- **非数值外挂**：雨泠初期身体素质仅为正常健康青年偏上，魔力量几乎为零，绝不能硬扛高阶强者正面火力。
- **高专注消耗**：深度开启【断点解构】拆解复杂杀阵或强敌后，会产生强烈的精神倦怠与头痛，不宜恋战——这与他“救完人立刻抽身跑路”的习惯高度自洽。
- **对纯物理碾压与无解人海受限**：即便看见断点，若没有够得着断点的角度、工具或体能，依然必须借助地形、偷袭或撤退周旋。
- **看不透“非敌意的人心执念”**：【断点解构】擅长拆解招式与杀局，却拆不掉温柔礼貌背后那份近乎窒息的偏执占有欲。
