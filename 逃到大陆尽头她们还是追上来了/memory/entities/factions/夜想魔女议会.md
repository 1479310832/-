# 夜想魔女议会

- **定位**：统辖奥尔兰大陆西南禁忌林海『永暮森域』的魔女最高自治议会，不受世俗王国与白昼教廷律法约束，专精高阶秘术、炼金药剂、结界与异界禁忌研究。
- **叙事功能**：掌控西南森域、荒野古道与黑市魔导渠道，在第三卷中通过使魔鸦群与秘术哨站专门封堵雨泠绕开城镇与干道的逃亡路线。
