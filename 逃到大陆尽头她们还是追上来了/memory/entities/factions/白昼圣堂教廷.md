# 白昼圣堂教廷

- **定位**：横跨奥尔兰大陆的宗教权威，在大小城镇均设有修道院、礼拜堂与救济院，掌握着最隐蔽的底层民众与告解耳目；麾下既有护卫圣女正统的护教圣殿骑士团（配随军圣器『护教涤罪钟』与驱散魔瘴的『白昼净光圣炬』），也设有专司越界猎巫的异端审问局。
- **叙事功能**：为艾琳娜提供遍布大陆的温和罗网——雨泠每躲进一座偏僻小镇，只要镇上有白昼礼拜堂，就随时可能落入圣女温和微笑的注视之下。
