# 罗斯韦尔公爵领（白蔷薇家）

- **定位**：圣瓦伦王国东北部最富庶的世袭大公领，以白蔷薇纹章闻名，掌控跨国商路、边境商税关卡与庞大贵族情报网。
- **核心矛盾**：老罗斯韦尔公爵暴毙当夜突发继承权政变，伊薇特在雨夜绝境中获刚身穿异界的雨泠所救；半年后她铁血清算掌权，白蔷薇情报网与封城关卡随之化作全大陆第一张撒向雨泠的天罗地网。
