# 樟木城

- **特征**：白昼圣堂教廷中腹交通咽喉大城，因城内遍植百年香樟得名；城西设有跨河大渡口通往西方平原，城南则保留着僻静幽深的白樟修道院旧侧廊与告解礼拜堂。
- **剧情功能**：第二卷中段双女主暗流交汇重镇。伊薇特派出的伪装白蔷薇商队抢先卡住城西渡口，逼得避雨绕行的雨泠在 E06 尾段潜入城南修道院旧侧廊，直接引出 E07 告解室隔板后的圣女低语交锋。
