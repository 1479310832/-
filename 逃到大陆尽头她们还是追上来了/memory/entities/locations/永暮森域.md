# 永暮森域

- **特征**：横亘于奥尔兰大陆西南部的广袤禁忌林海，因上古魔力折射使林间常年笼罩在紫金色黄昏天象下而得名；与圣瓦伦王国、白昼教廷、北境铁壁要塞并列为内陆四大版图疆域。
- **剧情功能**：第二卷末雨泠为避开教廷与白蔷薇双线夹击折入其外围，开启第三卷营救夜想魔女维奥莱塔与遗留现代金属打火机的主线舞台。
