# 永暮森域

- **特征**：横亘于奥尔兰大陆西南部的广袤禁忌林海，因上古魔力折射使林间常年笼罩在紫金色黄昏天象下而得名；除北侧边缘一条荒废古商道外，林海内部由地脉暗纹与浓雾构成巨型诱导结界（古杉四面绒苔等厚、溪流沿漫坡向高处倒流），擅离古道的外人极易迷失方位并被导入魔女驻守的断崖黑曜石尖塔。
- **剧情功能**：第二卷末雨泠为避开教廷与白蔷薇双线夹击折入其外围；第三卷开篇（E09-01）雨泠在此破阵救下维奥莱塔、留下无油金属打火机秒溜，却在绕避审问局援军时被诱导结界引入维奥莱塔驻守北境的双头黑鸦尖塔门前。
