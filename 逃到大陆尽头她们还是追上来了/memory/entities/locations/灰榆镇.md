# 灰榆镇

- **特征**：铺设黄铜魔石街灯的商业石板街、冒险者公会分部、商业公会下属『铁蹄马车工坊』、冒险者常聚的『橡木桶亭』酒馆食堂、挂松果木牌的『老松木亭』宿屋、北门贵族迎宾馆。
- **剧情记录**：雨泠在此隐姓埋名于马车工坊打黑工半年学字攒钱，后遭伊薇特亲自率队封锁四门，北门迎宾馆遇袭当夜雨泠破局翻西南断墙渡灰水界河脱逃。
