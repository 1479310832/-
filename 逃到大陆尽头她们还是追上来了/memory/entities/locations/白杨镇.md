# 白杨镇

- **特征**：白昼圣堂教廷东北边界的阴雨小镇，鹅卵石街、集市石桥与镇北山坡上爬满常春藤的石砌礼拜堂。
- **剧情记录**：E04-01 尾段雨泠逃离灰榆镇两日后潜入此地，在礼拜堂铁门缝里首次与被银链束腕的艾琳娜对视，开启第二卷。
