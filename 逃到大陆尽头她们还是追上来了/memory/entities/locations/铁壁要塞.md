# 铁壁要塞（赤铁边塞）

- **特征**：坐落于奥尔兰大陆北部苦寒雪山隘口咽喉的重装军事边塞，因城垣混铸暗红赤铁矿渣抵御魔物与攻城炮击而又称『赤铁边塞』，扼守北境绕越白浪河大峡谷通往西海岸的唯一高寒陆路通道『赤铁军道』。
- **剧情功能**：第三卷末（E12）雨泠被迫放弃西行平原干道后的北折目标地，也是第四卷核心舞台（女骑士长芙蕾雅驻守地）。
