# 银轮城

- **特征**：坐落于白浪河西干流峡口与多条陆路商贸干道交汇处的大陆西部咽喉重镇，由四国大商会联合组成的『银轮商业评议会』自治管辖，城内维持通商中立，不允许单一王国或教廷私设军管宵禁与私人通缉榜。
- **核心地标与空间结构**：
  - **双生银铁水轮**：横跨白浪河西干流急流峡口南北两侧的两座百米高巨型银铁水轮（『北银轮』与『南银轮』），日夜转动驱动全城水闸、磨坊与锻压工坊，轮下激起常年不散的白色水雾。
  - **银轮锁桥**：夹在南北双生水轮之间的唯一跨河石拱廊桥，扼守西赴『落日自由港』的陆路咽喉，每日暮钟落闸封桥；桥东广场北侧设有半敞式的『临河迎宾露台』与十余米高的『桥头税关钟楼』，隔着十米宽的引水急流槽与南侧低矮带水雾遮蔽的『南轮机括石廊』相望。
  - **南水门与西河马市**：城南临近驳船码头的『南水门』搬运工混杂；城西靠近桥东广场的『西河马市』（含『铜蹄马行』等大型车马商行）掌控过境快马与轻骑交易。
  - **北城门与铁轮商会第三盐库**：城北通往『赤铁军道』与北侧古商道的陆路城门为『北城门』；紧邻北城墙内侧废弃水道的石造仓库『铁轮商会第三盐库』后院连着直穿城墙地基的『北渠旧水闸』，被灰铜铃结社暗中租作西部违禁源质转运据点。
- **剧情功能**：第三卷中后段（E11～E12）核心舞台。雨泠在『银轮锁桥』撞破三女主信物修罗场后退入内城，继而在北城区利用灰铜铃『第三盐库』据点与三女主严防对方独占的心理死结，由『北渠旧水闸』脱身北折奔赴『铁壁要塞』。
