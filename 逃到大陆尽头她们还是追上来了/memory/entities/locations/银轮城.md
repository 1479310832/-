# 银轮城

- **特征**：坐落于白浪河西干流与多条陆路商贸干道交汇处的大陆西部咽喉重镇，因河道上两座高达百米的巨型银铁水轮与鳞次栉比的车马商行仓库得名，四国商旅混杂，车马交易繁盛。
- **剧情功能**：第三卷中点（E11）核心修罗场舞台。雨泠冲出『永暮森域』断风山口后赶往此城购置快马西进，恰与进驻东郊的伊薇特本阵、沿北侧古商道赶来的艾琳娜专驾及抄西南旧猎道追至的维奥莱塔正面汇聚。
