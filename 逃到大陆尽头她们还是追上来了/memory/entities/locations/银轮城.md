# 银轮城

- **特征**：坐落于白浪河西干流峡口与多条陆路商贸干道交汇处的大陆西部咽喉重镇，由四国大商会联合组成的『银轮商业评议会』自治管辖，城内维持通商中立，不允许单一王国或教廷私设军管宵禁与私人通缉榜。
- **核心地标与空间结构**：
  - **双生银铁水轮**：横跨白浪河西干流急流峡口南北两侧的两座百米高巨型银铁水轮（『北银轮』与『南银轮』），日夜转动驱动全城水闸、磨坊与锻压工坊，轮下激起常年不散的白色水雾。
  - **银轮锁桥**：夹在南北双生水轮之间的唯一跨河石拱廊桥，扼守西赴『落日自由港』的陆路咽喉，每日暮钟落闸封桥；桥东广场北侧设有半敞式的『临河迎宾露台』与十余米高的『桥头税关钟楼』，隔着十米宽的引水急流槽与南侧低矮带水雾遮蔽的『南轮机括石廊』相望。
  - **南水门与西河马市**：城南临近纤夫货栈与运河驳船码头的『南水门』人员混杂；城西靠近桥东广场的『西河马市』（含『铜蹄马行』等大型车马商行）掌控过境快马与轻骑交易。
- **剧情功能**：第三卷中点（E11）核心修罗场舞台。雨泠冲出『永暮森域』断风山口后赶往此城购置快马西进，恰与进驻东郊包销良驹的伊薇特本阵、沿北侧古商道赶来的艾琳娜专驾及抄西南旧猎道追至的维奥莱塔在『银轮锁桥』东堍正面汇聚。
