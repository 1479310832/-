# 风铃驿镇

- **特征**：白昼圣堂教廷东部腹地的热闹商路小镇，因镇口修道院塔楼悬挂祈福青铜风铃得名；街上设有冒险者公会分部、商业公会乘合马车站与挂着白木牌的『白鸽亭』宿屋食堂。
- **剧情功能**：第二卷 E06 舞台。艾琳娜下达三教区温柔密谕后，全镇关卡神官、修女与宿屋看板娘对黑发旅人展开无微不至的免检与免费白麦面包款待，雨泠在此识破圣女的“温柔引流软网”并顺手破坏灰铜铃余党的桥底魔石暗算。
