# 第一卷节奏卡：《白蔷薇的旧账》（vol-01.md）

## 卷定位
- **全书承接 Beats**：Opening Image → Theme Stated → Setup → Catalyst → Debate → Break Into Two（Beat 1~6）
- **卷核心目标**：确立低魔写实中世纪质感与【断点解构】的战术爽感；完整打响「别扭救下伊薇特 → 披衣后拂晓不告而别 → 半年后铁血女公爵封城堵门 → 极度压迫的礼貌猫鼠拉扯 → 破局逃往圣堂教区」的黄金闭环。
- **卷承诺感**：让读者在第一卷就彻底爱上「精致克制书面语 + 雨泠第一人称别扭内心戏 + 切入伊薇特视角时毛骨悚然的温柔执念」。
- **起点状态**：雨泠刚身穿坠入奥尔兰东北边陲荒林，身无长物，对异界一无所知。
- **卷末状态**：雨泠已摸清大陆格局与西行目标（落日自由港），靠【断点解构】惊险撕开白蔷薇封城网逃入教廷边界，正式背上第一笔甩不掉的“千里追夫债”。
- **卷末钩子**：雨泠刚踏入教廷边陲小镇松一口气，幕间切伊薇特视角——她抚平外套袖口，温和吩咐情报官把画师新绘的精准肖像送往白昼圣堂辖区边界；同时镇上破旧礼拜堂的钟声响起，引出第二卷艾琳娜。

## 卷内迷你弧（完整卷内骨架）
- **起点（Opening & Setup）**：身穿落地雨夜森林，误撞罗斯韦尔家族政变杀局。
- **卷内 Catalyst**：看穿死士剑阵与伏击法阵的结构断点，以普通青年之躯极限拆局，救下濒死的银发少女伊薇特；替她止血、披上深色现代外套、留一句别扭叮嘱后拂晓不告而别。
- **过渡与立规则（Fun & Grounding）**：半年低姿态蛰伏与西行启程——雨泠借边陲城镇打零工/帮小商队看货摸清奥尔兰语言文字、货币、剑技魔法常识，并打听到大陆最西端「落日自由港」的界隙传闻，准备动身西行。
- **卷内 Midpoint（首次压迫反转）**：白蔷薇家的悬赏寻人画像一夜贴满边城；城门无预兆落锁。雨泠本以为是领主抓逃犯，直到在酒馆瞥见画像里自己黑发黑眼的轮廓，更在次日客栈走廊听见门外那声温雅礼貌的叩门声——**伊薇特亲至**。
- **卷内 Pressure & Debate（高压猫鼠拉扯）**：伊薇特已铁血登位女公爵，全程语气温柔体面、滴水不漏，一面笑着替他结算“救命恩情”并展示那件洗净折叠的现代外套，一面不动声色把整座边城与客栈变成滴水不漏的华美鸟笼；雨泠表面冷静周旋、心里警铃狂响，真切体会到“毫无杀意却令人窒息”的偏执压迫。
- **卷内 Finale（破局脱身）**：雨泠以【断点解构】反向利用罗斯韦尔叛臣残党制造的混乱，抓住城防换班与仪轨法阵的毫秒级盲区惊险脱身，甚至临走前别扭地顺手替伊薇特挡掉了一枚暗箭/冷枪（彻底把伊薇特的执念烧到不可逆的沸点！）。
- **卷末收尾与钩子**：雨泠逃出罗斯韦尔领地边界踏入教廷辖区；切伊薇特幕间视角，看着城门外他为自己挡下暗算留下的半点痕迹，微笑着下令启动跨领千里追夫。

## 卷内职责段（交由 `novel-discuss` 拆解为事件卡，不预设死板章数）

1. **职责段 1（E01 · 雨夜拆局与拂晓离去）**：Opening Image + Catalyst 预热。雨泠身穿降临、撞进罗斯韦尔政变截杀、首次展露【断点解构】极限破局救伊薇特、披衣后趁天亮不告而别；末尾首次切入伊薇特短暂幕间（醒来攥紧外套、立誓寻回此人）。
2. **职责段 2（E02 · 边城蛰伏与西行启程）**：Setup。高密度推进半年间雨泠在异界立足、摸清常识与西行目标「落日自由港」，顺带通过一场小规模冲突展现他不惹事但绝不窝囊的性格底色，就在动身前夜，白蔷薇封城令骤降。
3. **职责段 3（E03 · 客栈叩门与体面罗网）**：Midpoint。伊薇特以女公爵之姿优雅登场，与雨泠展开第一场标志性的「礼貌潜台词 × 内心拉扯」高能交锋；雨泠发现城内退路全被她温柔锁死，切入伊薇特视角揭示她半年来的清算与偏执执念。
4. **职责段 4（E04 · 暗流破网与二度“不告而别”）**：Pressure + Finale + Hook。叛党残余趁女公爵微服寻人发动暗杀，雨泠借混乱用【断点解构】撕开封城防线脱身，却在跨出缺口前别扭出手替伊薇特化解致命冷袭——既惊险逃入教廷边界，又让伊薇特的千里追夫执念彻底焊死。

## 关键场景级事件清单（可直接转写作指令）
1. **雨夜古道拆阵**：雨泠毫无魔力，仅凭一块断石与半截折枝敲碎死士剑阵的发力断点，以近乎荒谬的冷静把伊薇特从死亡线上拖回来。
2. **客栈门扉的叩击**：雨泠刚扣好行囊准备趁夜出城，走廊烛光被修长阴影截断，门外响起两声从容叩门与那句温雅问候——门缝打开，她右手戴着纯白丝手套，臂弯里叠着他半年前丢下的旧外套。
3. **城门缺口的回身一挡**：雨泠明明已找到脱身缝隙可以立刻消失在夜雾里，却眼角瞥见暗处瞄准伊薇特后心的淬毒弩箭，嘴上低骂一句麻烦、顺手弹石破招后头也不回翻墙逃入教区——留伊薇特一人立在风中，眼底翡翠彻底烧亮。
