# 事件: 雨夜拆局与拂晓离去

## 定位
事件编号：E01
所属卷：Vol-01《白蔷薇的旧账》
全书 beat：Opening Image + Theme Stated + Catalyst 预热
起点：雨泠刚身穿坠入奥尔兰大陆东北边陲雨夜荒林，身无长物，尚不知身处何地；伊薇特遭家族政变截杀、贴身骑士倒戈，濒临死局。
终点：雨泠凭首次觉醒的【断点解构】极限破阵救出伊薇特，披衣后趁拂晓不告而别、启程踏入奥尔兰社会；伊薇特攥紧他遗落的深色现代连帽外套，立誓清算政敌并动用全领画师寻回此人。
承诺：开篇即兑现低魔写实中世纪质感、无数值外挂的精准战术拆局爽感、雨泠第一人称“别扭嘴硬但见死必救”的反差魅力，以及末尾切伊薇特视角时令人脊背发凉的执念引爆。
设计阶段：done

## 故事大纲
雨泠在现代雨夜失去意识后，身穿坠入奥尔兰大陆东北边陲的松林泥道。因为跨界伴生耳鸣使他虽不识异界文字却能听懂当地口语，他在躲雨探路时撞见前方倾覆的白蔷薇纹章马车与惨烈厮杀：罗斯韦尔公爵继承人伊薇特因老父暴毙遭遇旁系叔父发动政变，连贴身副官加雷斯都临阵倒戈，带领四名黑甲死士布下钉入地面的「缚魔银桩」封死她的魔力，步步逼近要斩草除根。雨泠本能地想趁雨夜悄悄绕走保命，却因骨子里的别扭看不惯围杀惨状，在危急关头视野骤然异变——剑阵交错的发力空隙、银桩之间连结魔力的薄弱节点在他眼中清晰浮现（【断点解构】首次触发，正文先呈现象不报名称）。因为本身毫无魔力且体能只是普通青年，他没有硬碰硬，而是用一块湿滑石片精准打歪阵眼银桩引发微弱魔力反冲，再借黑甲剑士收势不及的毫秒级破绽近身夺刃、反制加雷斯，硬生生撕开包围圈将重伤力竭的伊薇特拖入林深处一座废弃猎屋。由此，死士在后方重新集结放犬搜林，而猎屋内伤重惊疑的伊薇特第一次正视这个黑发黑眼、穿着古怪连帽衣却能徒手拆掉贵族杀阵的异乡青年，冷声质问他的身份与筹码（E01-01 终点）。

进入猎屋后，因为雨泠深度动用拆局直觉引发轻微头痛，加上林外马蹄与犬吠步步逼近，他一边别扭地替伊薇特简易止血包扎，一边看穿搜捕队追踪气味与火光的规律，外出故意在反方向泥地留下混杂血布与断枝的假痕引开追兵。回到猎屋时，伊薇特已从震惊中冷静下来，以贵族本能试探他索要什么爵位、金币或政治筹码；然而雨泠极度厌烦这种权谋交易和郑重道谢，不仅拒绝报出全名（只嫌麻烦随口留了个单字「雨」或敷衍搪塞），还因见她失血发抖、嫌她死在面前晦气，把自己的深色现代连帽外套直接扔在她肩上，撂下一句「天亮前别睡死过去，往南三里就是官道」便背身守夜。由于失血过多，伊薇特在拂晓雨停之际撑不住闭眼一瞬，再睁眼时炭火已熄、屋内空无一人，只剩肩头尚带体温的异界布料外套。随后罗斯韦尔家忠心旧部骑士终于循迹赶到，切入伊薇特第三人称视角：面对伏地请罪的属下，她冷静下令回城血洗叛党，指尖却死死抚过那件洗不掉雨味的深色袖口，下达了第二道密令——把全领最好的画师全部请进公爵府（E01-02 终点）。

## 章节拆分

### E01-01：泥水、剑阵与无名客
<东北边陲冷雨松林，泥泞古道，火把与马车残骸> [刚身穿落地、搞不清状况但先保命]（雨泠从湿冷苔藓中爬起，顶着短暂耳鸣摸清自己连人带深色连帽卫衣跌进了中世纪荒林，循着人声摸近古道）→ 撞见白蔷薇马车倾覆，一名银发少女持断剑背靠车轮，四名黑甲死士与倒戈副官加雷斯已将四根刻纹银桩钉入泥地围死退路
<雨幕压低火光，银桩间隐现暗淡蓝纹> [加雷斯以叛徒身份得意劝降、确认封魔阵生效] "老爵爷已逝，伊薇特小姐，省省力气吧——四方缚魔桩下，您连一星火花都唤不出来。" → 雨泠听懂异界口语（心中惊疑但无暇细究），目睹伊薇特在绝境中依旧维持冷冽贵族仪态、拒不求饶
[别扭天性发作：理智疯狂叫自己趁暗绕走，偏偏看不惯五人围杀重伤少女且副官嘴脸恶心]（雨泠在树影后攥紧一块带棱角的湿石，视线锁向场中时世界陡然失色，四根银桩与死士步法间浮现出几道极细的失衡断点）→ 首次触发异质洞察，发现加雷斯脚边那根歪斜三分的银桩正是整座阵法与左侧剑士步法的共同承重死穴
[没有魔力也绝非武者，赌一次出其不意的拆局]（雨泠未出声，借雷声掩护挥石砸偏那根银桩的受力斜角，同时贴地窜出）→ 银桩骤偏引发魔力回路瞬间错拍、蓝光倒冲震麻最近两名死士，雨泠踩泥滑步切入左侧剑士收剑的毫秒级空隙，一记肘击震脱其手腕并顺手夺下制式短剑
[加雷斯惊怒扑杀，视无魔力黑发怪人为刺客]（雨泠无力硬拼力量，仅凭视野里的发力断点侧身半寸卸开斩击、借力一脚踹在加雷斯膝弯发力死点并将其撞向残破车辕）→ 加雷斯重创撞翻火把、阵型彻底大乱；雨泠深感一阵尖锐头痛袭来，暗骂自己多管闲事，一把拽起惊愕的伊薇特冲进漆黑密林
<林深处半塌废弃猎屋，炭盆冰凉，林外重新响起急促哨声与猎犬狂吠> [雨泠喘着粗气抵住破门，只想等追兵过去就脱身]（伊薇特肩侧渗血却迅速稳住呼吸，左手稳稳攥住雨泠浸透雨水的卫衣袖口，冷翡翠眼眸在门缝漏进的微光里紧紧锁住这张异域黑发面孔）→ "你既无魔力波动，亦非白蔷薇或叔父麾下之人——拆毁四方缚魔阵却不报家门，阁下究竟是谁，又想要什么价码？"（强钩子收尾）

### E01-02：披衣、拂晓与第一笔旧账
<废弃猎屋内，雨声拍打残瓦，犬吠由远及近> [头痛未退且懒得废话，先解决眼下追兵]（雨泠甩开她的手却没真甩狠，冷淡抛出一句先保命再谈价码，翻找出猎屋残布替她草草压住肩伤，随后透过窗缝观察林外火把移动轨迹与猎犬嗅探空档）→ 发现搜捕队过度依赖猎犬嗅觉与火把直线推进，找到反向布疑阵的断点
[独自引开追兵，顺便看准脱身路线]（雨泠将沾有伊薇特血迹的半截断带与死士铁徽顺着下风口溪涧扔向北坡断崖，自己绕回猎屋）→ 林外哨声与犬吠被成功引往北坡，猎屋周围暂归死寂
<猎屋内生起一小堆无烟暗炭，气氛冷冽紧绷> [伊薇特试探底细、按贵族逻辑亮出筹码与庇护承诺] "罗斯韦尔公爵领绝不亏欠救命之恩。报上你的名字，金币、领地或是骑士爵位，待我回城清洗叛党之后，皆可兑现。" → 雨泠内心极度别扭烦躁（既不想卷进贵族权谋，又听不得这种像签卖身契似的郑重报恩），随口搪塞只说路过嫌吵、连全名都不给，只嫌她失血发抖、随手脱下深色现代连帽外套丢过去盖在她肩头
[伊薇特触及陌生而温暖的现代织物，第一次对「毫无所求的善意」感到失控与震动] "你不要赏赐，也不肯留名？这世上没有不索回报的救赎。" → 雨泠皱眉避开她灼人的翡翠视线，只扔下一句「天亮前别睡死过去，往南三里便是官道，你的人自然找得到你」，转身背对她靠在门边守夜
<拂晓雨停，雾气漫进门缝> [失血脱力的伊薇特撑不住闭眼片刻]（再睁眼时炭盆已冷，破木门半掩，门外泥地上连半个新鲜脚印都已被晨露冲淡，肩上只留那件尚存余温的深色连帽外套）→ 雨泠已不告而别，独自踏上往西南边城摸清异界的旅途
◆ 切换伊薇特视角 ◆ <猎屋外林道，马蹄骤停，迟来的忠心近卫队长跪地请罪> [伊薇特独自起身走出猎屋，右手缓缓拉紧袖口、将那件格格不入的深色外套细致叠好抱在臂弯]（她望着南方空荡荡的雾林，唇角弯起一抹极礼貌却让老骑士背脊发凉的浅笑）→ "先随我回白蔷薇堡，把叔父和加雷斯的债一笔笔算清。至于第二件事——传令下去，明日起，把全领最好的画师都请进公爵府。救命之恩未结，那位阁下逃不掉的。"

## 角色动态
- 主角：雨泠主动决定不绕走而强行介入死局，用一块湿石与夺来的短刃精准拆掉高阶封魔杀阵并全身而退，事后拒绝一切贵族筹码与纠缠、丢衣拂晓离开——冷静拆局的狠劲与拒绝人情的别扭反差拉满。
- 阻力源：倒戈副官加雷斯与四名黑甲死士（E01-01 物理死局）；林外猎犬搜捕队与伊薇特敏锐的权谋试探（E01-02 双重压迫）。
