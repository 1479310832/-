# 事件: 客栈叩门与体面罗网

## 定位
事件编号：E03
所属卷：Vol-01《白蔷薇的旧账》
全书 beat：Midpoint（首次高压重逢）+ Debate（顺从鸟笼 vs 破网西逃）
起点：雨泠刚在老松木客栈二楼收拾好行囊欲翻后窗逃出灰榆镇，门外长廊靴声停在房门口，响起两声礼貌叩门。
终点：雨泠被迫随伊薇特入住重兵把守的北门驿馆，晚宴上正面撕破体面假面、直面她令人窒息的偏执执念；恰在僵持之际，罗斯韦尔叛党残余夜袭驿馆，打破僵局并为 E04 破网脱身埋下引信。

设计阶段：done

## 故事大纲
老松木客栈二楼门外站着的正是亲临灰榆镇的女公爵伊薇特。她一句话点破后窗小巷已布满十二名白蔷薇弩手，彻底断了雨泠硬闯的念头。雨泠压下烦躁拉开门，见伊薇特换上一身墨蓝银纹骑装大衣，臂弯里竟整整齐齐搭着他半年前丢在东林的那件深灰连帽卫衣。她令近卫队长布兰德退至楼梯口，独自入房与雨泠对坐，一边以无可挑剔的贵族礼仪寒暄，一边步步拆穿他半年在灰榆镇车行记账留下的现代硬笔笔锋、以及半个时辰前把地痞巴顿掀进油桶的行踪，随即以“客栈潮湿、全城宵禁”为由发出无法拒绝的体面邀请，请他移步北门驿馆小住结清旧账。雨泠审时度势暂时应承随行，却在离开客栈长街时注意到暗处一辆挂着灰铜铃铛的陌生黑马车，而伊薇特登车前微笑挑明她并不打算真的归还卫衣，只是确认他有没有别的旧物轻易留给旁人（E03-01 终点）。

抵达北门驿馆后，雨泠借餐前踱步庭院，浅层运转眼力勘测布防，惊觉外院三层暗哨与内院新型双环警讯阵竟是专门针对他半年前拆毁银桩的手法改良而成，连寻常盲区都被填平。烛光长桌前只摆两副银餐具，伊薇特亲手斟酒，温雅点破他藏在床板下想去西边「落日自由港」的打算，并直接抛出一座华美鸟笼的蓝图——请他随自己回白蔷薇堡衣食无忧度日。雨泠彻底绷不住别扭克制，正面硬刚拒绝成为贵族藏品，直言哪怕调来全领骑士他也总有办法离开；这一句直球撕裂了餐桌上的优雅假面，伊薇特放下银叉，第一次毫无掩饰地道出她半年来偏执寻人的真正缘由：在所有人拿刀称量她性命的雨夜里，只有他扔下唯一的干衣便转身离去，她绝不允许他再从眼前消失第二次。恰在两人剑拔弩张的刹那，外院轰然响起爆炸与布兰德的急喝——流亡叛党残余趁女公爵微服出巡，借暗处陌生势力发动了致命夜袭。切入伊薇特视角，她第一念不是自保，而是看见雨泠皱眉扫视窗外破绽、半步未退的身影，眼底滚烫执念随之锁死（E03-02 终点）。

## 章节拆分

### E03-01：门外靴声与旧外套
<老松木客栈二楼偏房，油灯昏黄，后窗冷风倒灌> [门外两声叩门声后响起伊薇特平缓语调，直接点破后窗小巷埋伏着十二名白蔷薇弩手] "雨阁下若是想走后窗，楼下小巷此刻站着十二名白蔷薇弩手，恐怕不太方便。" → 雨泠确认硬翻窗必死，压下烦躁收好短刃拉开门栓
<敞开的木门前，半年不见的伊薇特身着墨蓝银纹骑装、右手白丝手套、左臂搭着洗净折好的深灰现代连帽卫衣> [伊薇特遣退老队长布兰德，独自入房行礼落座，以礼貌潜台词展开猫鼠交锋] "半年不见，阁下清瘦了些。东林欠您的衣服，今日亲自送还。" → 雨泠别扭推辞，却被她轻描淡写拆穿车行账本上奇特的现代硬笔笔锋与刚把巴顿掀进黑油桶的细节，意识到自己早已被她精准锁死
[伊薇特以四门宵禁与客栈简陋为由，体面邀请雨泠随车移步北门驿馆「小住结账」]（雨泠看清门外亲卫与楼下弩阵无懈可击，决定暂且顺坡下驴进驿馆再寻脱身破绽）→ 随她走出老松木客栈，途经暗巷口瞥见一辆悬着灰铜铃铛的无徽黑马车（埋下叛党夜袭伏笔）
<白蔷薇主马车阶前，夜风渐冷> [伊薇特登车前替他拂开车帘，笑着说出令雨泠心头发紧的尾句] "其实这件外套我并不打算真的还你——只是借它看看，阁下身上还有没有别的旧物，也这么轻易留给旁人。" → 强心理压迫钩子收尾

### E03-02：鸟笼里的体面晚餐
<北门驿馆改建的临时行邸，石砌庭院与重重灯火> [雨泠借晚宴前洗漱在庭院缓步，浅层动用洞察勘测出路]（扫过外院哨岗与内院石砖下的双环魔导警讯纹）→ 惊觉布防专门针对他半年前的破阵习惯做过双节点冗余，寻常漏洞全被堵死，只能等外部变数
<驿馆二楼长厅，烛光摇曳，长桌只设两副银餐具> [伊薇特屏退侍从亲手斟酒，温雅闲聊间顺手点破雨泠床板下那张西行「落日自由港」路线图，邀他随回白蔷薇堡安稳度日] "西边教区鱼龙混杂，何必吃那份苦？留在白蔷薇堡，你要清静我便给你整座南翼庄园，何必再奔波？" → 雨泠听出华美鸟笼的窒息感，不再绕弯子，正面硬刚拒绝做贵族藏品
[雨泠直球挑明底线，彻底刺破餐桌上的礼貌假面] "你要算救命账，我认；可你要把我锁在白蔷薇堡里养着，就算调来全领骑士，我也总有办法走。" → 伊薇特放下银叉，第一次直白吐露雨夜以来深埋骨髓的执念：「你既然把我从泥里拉出来，就该料到，我绝不会允许你从眼前消失第二次。」
<外院骤响闷雷般的爆裂声，火光冲天，布兰德急促呼警> [流亡叛党勾结暗处死士夜袭驿馆，雨泠本能抢步至窗前锁定火光与阵势破绽] ◆ 切换伊薇特视角 ◆（她无视近在咫尺的暗袭警报，只静静看着雨泠皱眉挡在窗前半步未逃的背影，眼底冷意融成滚烫的笃定）→ "嘴上总说着最怕麻烦，真遇上死局，你还是第一时间站到了我身前。"（承接 E04 高燃破局逃亡）
