# 事件: 高墙晚钟与笼中圣女

## 定位
事件编号：E05
所属卷：Vol-02《笼中圣女与无名便条》开篇
全书 beat：B Story（第二女主关系主轴建立 + 双线追夫合流）
起点：雨泠逃至白昼圣堂东北边陲白杨镇，在细雨黄昏的旧礼拜堂铁栅门缝里，与腕绕符文银链的浅金发少女艾琳娜四目相对。
终点：雨泠夜探礼拜堂，静音拆解连着晚钟铜索的「净音银链」，见证艾琳娜反手制服腐败主教西蒙夺回密账；雨泠深感这女人同样危险，留下一张硬笔便条『别再回那个鸟笼』趁拂晓溜走；艾琳娜掌权后收到伊薇特跨领送来的白蔷薇协寻信，一面温言敷衍女公爵，一面下达圣女密谕独享追捕。
承诺：立住艾琳娜“披着白纱的温柔执棋者”反差魅力，用灰铜铃暗线自然串联雨泠出手动机，并在尾段引爆伊薇特来信与艾琳娜便条的隔空修罗场。
设计阶段：done

## 故事大纲
雨泠在白杨镇强行按下管闲事的冲动去杂货铺采买干粮、登记旅店，为避开白蔷薇通缉令上的单字「雨」，他随口用原词音 `Rain` 应付，被旅店老板娘记作平民名「瑞恩」，顺带听闻镇北旧礼拜堂里关着的圣女候补因拒绝配合边境主教西蒙敛财，明早总教区裁判团抵达前就会被灌下失声圣水沦为活体神像。雨泠本想睡醒就走，入夜却从旅店窗口瞥见一辆挂着旧灰铜铃铛的无徽黑篷车悄然驶上礼拜堂山坡——与灰榆镇刺杀伊薇特的暗面势力如出一辙。担心灰铜铃封锁西行商路，雨泠趁夜潜入礼拜堂，避开钟楼暗哨摸进地下祈祷室，恰撞见西蒙主教送走灰铜铃密使、命两名执事端着失声药剂逼近石座上的艾琳娜。雨泠吹熄壁灯借回音半拍卸翻两名执事，艾琳娜非但未惊，反而温声道出早已料到他会来；雨泠上前拆锁时看穿她腕上「净音银链」竟与头顶晚钟铜索共振相连，硬扯必惊动全镇，而走廊外已响起西蒙折返查锁的脚步声（E05-01 终点）。

危急间，艾琳娜从容递出双腕劝雨泠独自从气窗退走，激起雨泠别扭脾气。雨泠开启深层洞察看准银链第三环与钟索共振的唯一盲点，以短刃刀背垫槽，借西蒙推门声掩护寸劲震断内芯，银链无声脱落。重获圣术的艾琳娜瞬间褪去柔弱，抬手一道无声圣光禁言并定死西蒙主教，从其怀中搜出勾结灰铜铃暗面的铁证账册。雨泠见她手段如此果决利落，立刻明白这位圣女绝非善茬；带她由排水暗渠脱身至镇外山坡迎候总教区裁判团仪仗后，面对艾琳娜温柔追问姓名与盛情挽留，雨泠绝口不留名字，趁她低头整理圣典时撕下半角羊皮纸写下『别再回那个鸟笼』夹进扉页，借晨雾转身西逃。随后切入艾琳娜视角：她当场凭铁证将西蒙送入宗教裁判所、顺利执掌边境圣堂大权，并接到伊薇特悬赏三座银矿十一税协寻「雨」的亲笔信；她摩挲扉页上横平竖直的硬笔便条，顺藤查出白杨镇旅店昨夜登记的化名「瑞恩」，微笑着一面回信稳住伊薇特，一面传下圣女密谕，命西边三座教区修道院暗中将这位旅人引向自己掌心（E05-02 终点）。

## 章节拆分

### E05-01：铁门、银链与不该管的事
<白杨镇集市杂货铺与小旅店，黄昏潮气> [雨泠强行挪开脚步去买干粮住店，用 Rain 应付登记被记作「瑞恩」]（听老板娘闲谈镇北礼拜堂里的圣女候补因不肯低头，明早裁判团来前恐遭西蒙主教暗算失声）→ 雨泠嘴硬劝自己少管教廷烂账，回房歇息等天亮西行
<半夜旅店二楼窗边，冷月细雾> [睡不踏实的雨泠起身看街况，瞥见一辆悬着旧灰铜铃铛的无徽黑篷车摸黑驶向镇北礼拜堂]（意识到灰榆镇那股暗面势力竟也渗透进了圣堂边境，怕西行官道有诈，找足理由决定摸上去探个究竟）→ 潜上北坡翻入礼拜堂后院，浅层拆解巡夜执事视野盲区摸进地下祈祷室
<阴冷石砌地下祈祷室，烛影摇晃，石座上浅金长发的艾琳娜腕绕符文银链> [恰见西蒙主教送走黑袍密使，留下两名执事端失声药剂逼近艾琳娜]（雨泠弹石灭灯，借石室回音两步卸掉两名执事手腕与下颌将其打晕，未让外男碰到艾琳娜分毫）→ 艾琳娜在暗处抬头看他，语气温柔平和：「我就知道，黄昏在街口停下脚步的旅人，夜里还会再来的。」
<石座前，走廊上方突传西蒙主教去而复返的脚步声> [雨泠伸手欲撬银链，视野压上去却骤见银链符文直连钟楼铜索]（一旦蛮力扯断必撞响晚钟惊动全院护卫，而门外脚步已到石阶拐角）→ 强悬念收尾

◆ 切换艾琳娜视角 ◆ <半日后清洗一新的礼拜堂圣坛，阳光透过彩窗> [西蒙伏法，总教区裁判长恭呈罗斯韦尔女公爵伊薇特以三座银矿十一税协寻恩人「雨」的白蔷薇火漆信]（艾琳娜先摩挲圣典扉页上横平竖直的硬笔便条，再对照伊薇特信中黑发黑眼特征与属下刚查到的镇旅店昨夜化名「瑞恩」记录，温和弯起眉眼）→ 吩咐修女回信稳住伊薇特，同时向西边三座教区修道院下达密谕：「凡遇黑发黑眼或自称『瑞恩』的旅人，不必惊动，悄悄报到我案头便是。主既将他送到我面前，便没有让给世俗领主的道理。」

## 读者信息状态
