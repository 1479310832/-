# 事件: 紫金暮霭与无油火机

终点：雨泠滚石破阵反噬审问官，为防搜山猎犬顺藤摸瓜将脱力的维奥莱塔拎入玄武岩裂窟，以短刀挑开秘银护肋扣卸除破魔短矢；严词回绝她的『双生鸦契』后，留下仅能擦出火星的**无油旧金属打火机**点着驱瘴香绒，趁她昏睡十分钟内果断跑路；不料为躲北道审问局援军往南侧密林绕行半宿，反被森域折射迷雾扭曲方向误入夜想议会内圈黑曜石古阶，并在次章被缓过气、已用炼金油点亮打火机的维奥莱塔携漫天黑鸦当场截住。

## 故事大纲
对视不到半秒，正面石阶上的异端审问官察觉维奥莱塔视线飘向北坡，当即厉喝两名黑铁皮甲死士提毒剑搜坡！退路被封、再慢一秒不是挨砍就是陪葬自爆，雨泠果断朝石环内的维奥莱塔比了个压低头颅的手势，抬脚猛踹树根旁一块二十多斤重的棱角青石顺陡坡滚落。青石擦过搜坡死士，精准砸塌第三根封魔铁桩下的腐朽空心老杉树根；铁桩歪斜脱出地脉，六角禁魔光幕瞬间逆流炸裂，将两名主阵异端审问官震得吐血倒飞！维奥莱塔心领神会收起晶核，借残余魔力震碎裂纹黑曜石短杖化作漫天紫黑浓雾与惊飞鸦群。此时北侧古道远处响起审问局增援大队的铜哨与猎犬吠声，刚迈出石环便因左肋破魔短矢失血软倒的维奥莱塔一旦被抓或引爆，搜山犬必顺着滚石泥印咬死雨泠。雨泠骂骂咧咧滑下陡坡，避嫌只拎住她未染血的鸦羽披风厚领与右小臂外袖，借溪水断味钻入半公里外藤瀑遮掩的玄武岩裂隙石窟。

石窟内，脸色惨白的维奥莱塔强撑高傲审视这个毫无魔力却一眼破阵的黑发青年。雨泠看穿她左肋倒刺破魔短矢实则卡在披风内衬的秘银护肋暗扣上，用剥皮短刀刀尖隔衣轻挑簧片卸开倒刺拔出毒矢，将她腰间皮囊里的止血白藓粉与绷带丢回她怀里背身避嫌。不愿欠凡人因果的维奥莱塔包扎后划出暗紫符纹，冷声要他报上真名立下夜想议会的『双生鸦契』以便日后双倍偿还；多疑到骨子里的雨泠哪敢跟魔女签灵魂追踪契约，退开三米严词拒绝。恰逢破魔寒毒发作、林瘴渗入洞口，魔力紊乱的维奥莱塔连搓两次指尖都点不燃压制寒毒的『驱瘴安魂香绒』，失血眩晕渐重。雨泠急着趁审问局往北搜偏的空档开溜，摸出贴身内袋里那枚早已没油的**旧金属打火机**，「咔哒」擦出橘黄火星引燃香绒，避开她勉强抬起的手指，把这枚反正只剩打火石能擦响的铁壳子搁在她手边抵账，趁安魂香烟令她昏睡过去的瞬间背起行囊钻出藤瀑。为绕开北侧古道上的审问局搜山队，雨泠按地图与苔藓经验往西南侧翼密林迂回，满心以为天亮前就能切回西行边界把这危险魔女彻底甩掉；谁知在浓稠如琥珀的紫金迷雾里疾行三个多小时后，脚下腐叶竟变成了整齐上升的黑曜石古阶，树干四面青苔厚薄一致、连溪水都在逆流打转——当他头皮发麻停步回头时，成百上千只暗金瞳孔的紫黑使魔乌鸦已无声落满身后树冠，正前方浓雾裂开，露出缠满黑蔷薇与倒月鸦徽的夜想议会内圈黑石尖塔（E09-01 终点）。

## 章节拆分

### E09-01：碎桩、血契与走反的雾路
<永暮森域北侧古道四十米黑杉陡坡与下方古石环，紫金暮雾与狂暴电弧> [审问官察觉维奥莱塔视线异样，喝令两名死士摸上北坡搜查，雨泠退路被截]（雨泠果断冲石环内的维奥莱塔比出低头手势，一脚踹落树旁二十斤重青石顺陡坡砸塌第三根封魔铁桩下的腐朽空心树根；六芒禁魔阵失衡逆流炸飞两名异端审问官，维奥莱塔收起晶核震碎裂纹短杖掀开紫黑烟幕）→ 远处北道响起审问局援军铜哨与猎犬声，维奥莱塔左肋破魔矢渗血栽倒，雨泠怕猎犬顺滚石脚印追查自己，咬牙滑下陡坡拎住她披风厚领借溪水断味钻入藤瀑后的玄武岩裂窟
<藤蔓瀑布掩映的狭窄玄武岩裂窟，滴水声与冰冷破魔寒气> [维奥莱塔脸色苍白倚壁冷笑追问来历，左肋倒刺破魔短矢锁死魔力]（雨泠自称抄近道的黑户，压下视线看穿倒刺卡在披风内衬秘银护肋暗扣上，用剥皮短刀刀尖挑开簧片无损卸除短矢，把她皮囊里的止血白藓粉与绷带丢给她自己包扎，全程转身守在洞口避嫌）→ 维奥莱塔包好伤处，指尖凝出暗紫契纹傲然要求他报真名立『双生鸦契』结清救命债；多疑的雨泠当场退开三步严词拒签任何魔力卖身契
<寒气与林瘴渗入裂窟，灰绿色『驱瘴安魂香绒』搁在石面> [维奥莱塔魔力紊乱连打两次指响都点不着香绒，失血昏沉渐重]（雨泠听见外头搜山犬队往北偏远急欲脱身，掏出内袋里早已干油的**旧金属打火机**，拇指挑盖擦出橘黄火星点着易燃香绒；避开她抬起欲抓衣角的手，随手把只剩打火石的铁壳打火机搁在她手边留话两清，趁她吸入安魂香昏睡过去，十秒内钻出藤瀑溜之大吉）→ 第三卷核心信物『现代金属打火机』自然完成移交！
<浓稠如蜜的紫金色迷雾古林 → 诡异抬升的黑曜石古阶与漫天鸦群> [北侧外围古道已被审问局援军封死，雨泠决定往南侧密林迂回四公里再借苔藓溪流切回西路]（一口气摸黑疾行三个钟头，满以为早把那疯批魔女甩在身后，脚下松软腐叶却突兀踩上冰硬整齐的黑曜石石阶；蹲身一摸树干四面青苔竟一般厚，溪水更绕着古柱向南倒流——森域折射磁场早已拧反了方向感！）→ 猛然回头，上千只暗金眼珠的紫黑使魔乌鸦无声蹲满身后树冠封死来路，前方浓雾裂开浮现悬挂倒月鸦徽的高耸黑石尖塔，风中飘来熟悉的安魂苦艾香！（反套路强悬念收尾，直连 E09-02 维奥莱塔主场按亮打火机堵门！）
