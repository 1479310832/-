# 事件: 三方掣肘与北折铁壁

## 定位
事件编号：E12
所属卷：Vol-03《永暮火苗与枢纽修罗场》收官事件（第三卷终章组）
全书 beat：Midpoint 余波升级 → Bad Guys Close In 入口（Beat 9 尾 → Beat 10 开启）
起点：入林第 3 天入夜，『银轮锁桥』彻底落闸封死，伊薇特、艾琳娜、维奥莱塔分守『银轮城』四门并派出耳目巡视街道；退入内城夜巷的雨泠身怀九枚银朗与剩余的四把尖塔小号黄铜钥匙，潜往北城区探查『北城门』出城空隙。
终点：雨泠避开三方夜间暗哨，发现『北城门』内侧广场已被艾琳娜的免检专驾与护教圣殿骑士重点盯防，遂检查上午从黑石尖塔内鬼女巫处缴获的『防水油纸草图』，发现纸角『银轮城』背面留有无墨细针压出的『三齿铁轮』暗记，顺藤摸瓜找到北城墙内侧废弃水道尽头的灰铜铃转运据点『铁轮商会第三盐库』，撞破其与圣瓦伦前军官联络人偷运『蚀脉源质晶罐』前往北境『铁壁要塞』外围、并准备在凌晨纵火焚烧邻近织物街市掩护开启后院『北渠旧水闸』出城的计划；雨泠静音制伏后院守卫、破坏火油车引信，随后在正门街灯下故意向使魔哨鸦暴露半秒身影并丢下一把尖塔小号黄铜钥匙，连环引动维奥莱塔、伊薇特与艾琳娜三方主力同时合围盐库正门（E12-01 终点）；趁三女破门清剿灰铜铃据点又因扑空互相牵制之机，雨泠借前院魔力碰撞声掩护松开后院『北渠旧水闸』绞盘钻出北城墙，在城外两公里荒林草棚留下八枚银朗买走灰铜铃预备的耐寒挽马，踏上正北偏西的『赤铁军道』，数日后在漫天初雪中抵近狼烟四起的『铁壁要塞』外隘，遥见城头酒红高马尾女骑士长芙蕾雅，第三卷完结（E12-02 终点）。
承诺：以克制洗练的纯正日轻笔调兑现高智商猫鼠破局——不留任何新贴身信物，仅用一枚剩余的魔女尖塔小铜匙便撬动三位女主的互相戒备心理，借三方之手粉碎灰铜铃军火转运站并调空北门防线脱身，自然引出第四卷北境孤城篇章。
设计阶段：done

## 故事大纲
因为『银轮城』受四国通商公约保护，伊薇特、艾琳娜、维奥莱塔无法在城内动用军队逐户搜查，所以入夜后三方改以各自方式在街道布网：罗斯韦尔商会的书记官逐一核对正规宿屋的入住名册，白昼圣堂的修女在北城十字街口设立热汤休息点温和观察夜行旅人，维奥莱塔的使魔乌鸦则停在高处街灯横杆上紧盯另外两方人员。因此雨泠避开所有需要登记的宿屋，在北城商队街一处免登记的夜间马车夫休息棚花两枚铜币买下热大麦汤与黑色羊毛围巾遮住后颈黑发，随后登上停用的旧谷物塔观察『北城门』，发现艾琳娜将四国免检素白专驾直接停在城门内侧石坪旁、两队护教圣殿骑士分列值守，正面出城已无可能。

由此雨泠取出上午从黑石尖塔灰袍执事女巫身上搜出的『防水油纸草图』仔细检查，发现在右下角『银轮城』墨字背面，有细针压出的无墨『三齿铁轮与枯水渠』标记，对应北城墙西侧废弃运河支流尽头的石造仓库『铁轮商会第三盐库』。雨泠潜至盐库屋顶天窗观察底仓，发现四名灰铜铃成员正与一名圣瓦伦口音的退役军官联络人装运六箱铅封『蚀脉源质晶罐』（买主位于北境『铁壁要塞』外围攻城营地），且对方准备在凌晨三点推火油板车去东侧两条街外的织物市场纵火制造混乱，趁评议会卫兵救火时绞开后院穿过北城墙地基的『北渠旧水闸』暗涵运货出城。

因为底仓有五名持弩与佩剑的敌人看守，单人硬动绞盘必会暴露，且雨泠绝不愿看着平民街市被烧毁，所以他决定利用三位女主“绝不容许另外两方抢先带走他”的戒备心理借力破局。他滑入后院制伏捆好水闸守卫、刮去火油车引信管内的磷粉；随后绕至盐库正门外的魔石街灯下，故意向灯杆顶端的使魔哨鸦露出半秒旧毡帽下的黑发侧影，随手将包里挑剩的一把『黑石尖塔药库黄铜小钥匙』丢在盐库正门石阶前，立刻从侧巷折返后院潜伏。哨鸦衔起尖塔铜匙升空啼鸣，引来维奥莱塔与鸦群疾驰而至；一直监视鸦群动向的罗斯韦尔巡夜骑手与北门护教圣殿骑士认定维奥莱塔找到了雨泠企图独占，伊薇特与艾琳娜随即率队从另外两条街道同时赶到——盐库内的灰铜铃成员见三方势力同时破门顿时陷入恐慌，后院阴影中的雨泠则已握紧『北渠旧水闸』绞盘的止动铁销（E12-01 终点）。

随着紫雷、冰霜与纯白圣光同时轰开盐库正门，负隅顽抗的灰铜铃成员与联络官在极短时间内被彻底制服，六箱『蚀脉源质晶罐』全数截留。雨泠趁前院魔力碰撞声掩盖铁链摩擦声，拔下止动铁销松开绞盘，将『北渠旧水闸』抬起半米高空隙，钻过北城墙地基下的干涸水道离开银轮城。在城北两公里外芦苇林的接应木棚里，雨泠找到灰铜铃预备的两匹北境耐寒挽马，放走一匹混淆痕迹，并在木桩上留下八枚银朗抵付马价（仅留一枚银朗与零散铜币），翻身上马沿正北偏西的『赤铁军道』疾行远去。盐库内扑空的三位女主看着石阶前的尖塔小铜匙与敞开的后院水闸，明白被他借手清场脱身，随即各自传令向北线延伸追查；数日后初雪落下，雨泠骑马抵达狼烟升腾的『铁壁要塞』外围山道，远远望见暗红城墙上方那名束着酒红高马尾、身披残破暗红披风按剑迎敌的年轻女骑士长芙蕾雅，第三卷正式收束（E12-02 终点）。

## 章节拆分

### E12-01：夜间巡哨与盐库铜匙
- 北城商队街避开查册宿屋与圣堂汤棚，花两枚铜币购热麦汤与黑羊毛围巾遮掩黑发 → 登旧谷物塔确认艾琳娜专驾与护教骑士已封住『北城门』 → 细查灰袍女巫遗留的『防水油纸草图』背面无墨针印，锁定北城墙废弃运河尽头的『铁轮商会第三盐库』 → 潜上盐库屋顶天窗，听破灰铜铃向『铁壁要塞』外围走私『蚀脉源质晶罐』及凌晨纵火焚烧织物街市、经后院『北渠旧水闸』出城的计划 → 滑下后院静音制伏水闸守卫、刮除火油板车磷粉引信 → 绕至前街路灯下向使魔哨鸦露半秒侧影并丢下一把尖塔小号黄铜钥匙，引爆维奥莱塔、伊薇特、艾琳娜三方同时合围破门，雨泠在后院握住水闸绞盘铁销待发。

### E12-02：水闸脱身与初雪军道（第三卷终）
- 前院紫雷、冰霜与圣光瞬间碾平灰铜铃据点，雨泠借轰鸣掩护松开绞盘抬起『北渠旧水闸』半米空隙，穿过城墙地基干涸暗涵出城 → 城外两公里荒林木棚留八枚银朗取走一匹耐寒挽马，踏上正北偏西『赤铁军道』 → `◆　◆　◆` 切单人女主有限视角：三女在盐库见尖塔小铜匙、违禁源质箱与敞开水闸，确认被他借刀脱身，各自调动眼线向北境延伸 → `◇　◇　◇` 四日后『赤铁军道』初雪山岭，雨泠遥望遭魔导炮围攻的暗红『铁壁要塞』与城头酒红高马尾女骑士长芙蕾雅，第三卷完结。
