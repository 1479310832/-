# 世界观总览

## 一、世界本质（模块 1 · 文库本日式中世纪异世界）
- **题材定位**：纯正文库本风格的日式中世纪异世界轻小说（剑与魔法、冒险者公会、商业公会、魔石灯与生活魔导具、教会修道院、魔女结社与贵族领地并存）。
- **核心原则（零法则强制爱 + 日轻重女修罗场）**：本世界不存在强迫情感或绑定命运的爱情外挂法则。一切偏执与千里追夫皆源于雨泠身为现代普通青年的别扭温柔——在阶级森严的异世界里，他随手拆局救完人、嫌麻烦不留真名转身就溜，硬生生把各路美少女大佬变成了执念深重的「重女（病娇）」。
- **开篇叙事方式**：顺序从头开局——从雨泠身穿降临异世界第一天写起，兼具现代青年的冷吐槽松弛感与重女步步紧逼的猫鼠修罗场张力。

## 二、力量与社会生态（模块 2~3 · 纯正日轻基建）
- **异界超凡与日常生态**：
  - **魔力与剑技**：骑士与前卫冒险者通过体内魔力运转施展【身体强化】与流派剑技（无中式“斗气/内力”）；施法者与圣职者分别使用属性魔法、魔导阵与神圣术式。
  - **公会与城镇日常**：城镇普遍设有**冒险者公会支部**（发放魔物讨伐与护卫委托，凭金属识别牌证明身份）与**商业公会**；街道与室内照明普及**魔石灯 / 魔导提灯**；旅人投宿于一楼兼营食堂酒馆、二楼设客房的**旅店（宿屋）**。
- **雨泠的身穿异质能力**：【断点解构】（详见 `memory/entities/concepts/断点解构.md`）。纯靠眼力看穿魔导回路卡扣、剑技重心失衡与防线死角，借普通工具取巧拆局（绝非武侠高手，硬拆大阵会引发剧烈脑仁抽痛）。

## 三、势力与地理格局（模块 3~5 · 已定核心舞台）
- **舞台**：**奥尔兰大陆**（东北为圣瓦伦王国及罗斯韦尔公爵领，中腹为白昼圣堂教廷核心教区，南西旧林为灰塔魔女结社势力范围，北境边塞由铁壁骑士团扼守；大陆最西端临海处为不受四国管辖、传闻藏有远古「界隙遗迹」的**落日自由港**）。
- **四大势力（对应 4 位核心女主）**：罗斯韦尔公爵领（伊薇特）/ 白昼圣堂教廷（艾琳娜）/ 灰塔魔女结社（维奥莱塔）/ 北境铁壁骑士团（芙蕾雅）。四方表面维持均势，实则暗流涌动。
